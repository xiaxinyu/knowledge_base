## 2. 用程序把“不能开机 / 报警 / 自动停”钉死

### 2.1 启动被挡住时看什么（段：`启动停止`）

启动置位 `W21.00` 的条件（逻辑摘要）：

```
启动条件成立 ← 0.01 启动 或 W219.01 或 T0088 或 30.11
              且 非 W21.09（停机保护 2 分钟）
              且 非 0.05（相序保护）
              且 非 0.04（急停）
              且 非 H10.00（远程控制停机保持）
              且 非 17.00
              且 非 W33.00（联锁停机标志）
              且 非 30.04
```

| 点位 | 符号注释 | 更像 | 现场怎么查 |
|------|----------|------|------------|
| **0.04** | 急停 | **硬件** | 急停按钮是否按下/线断；PLC 输入灯是否亮（注意程序按常闭思路用 `ANDNOT 0.04`） |
| **0.05** | 相序保护 | **硬件** | 相序继电器、供电相序；输入状态是否异常 |
| **0.11** | 空压机热保护 | **硬件** | 空压机热继电器是否跳；复位后输入是否恢复 |
| **H10.00** | 远程控制停机（保持） | **软件/通信** | 触摸屏或远程是否写了停机保持；上电是否残留 |
| **W21.09** | 停机保护 2 分钟 | **软件（时序）** | 刚停机后 2 分钟内无法再启，属设计，不是坏 |
| **W33.00** | （联锁停机，见报警段） | 软+硬 | 由急停/热保护等置位，见下节 |
| **30.04 / 30.11 / 17.00** | 符号表无中文名 | **待核对图纸** | 用万用表/输入灯对照电气图，优先当硬件联锁查 |

### 2.2 报警器何时响（段：`报警耗材设定`）

报警输出标志 **`W25.00`（报警器）** 置位条件（运行中 `W21.08` 为真时）：

| 条件 | 含义（按注释与比较指令） | 更像 |
|------|--------------------------|------|
| `D9 < #520` | 屏显空气压力偏低 | 硬件（传感器/气路）或设定 |
| `D11 < #350` | 屏显氧气压力偏低 | 硬件（传感器/气路）或设定 |
| `T0044` | 纯度相关延时到 | 纯度低持续一段时间 |
| `NOT W22.06` | 油温开关异常 | **硬件**（油温开关/接线） |
| `0.05` | 相序保护动作 | **硬件** |

自动复位报警（同梯级）要求大致：`D9>#500` 且 `D11>#370` 且 `W22.06` 且 `D62>#900` 等——说明 **压力/纯度回到窗口且油温正常** 才会消警。

强制联锁停机（置 `W33.00`，并清运行相关位）触发源：

| 条件 | 注释/含义 | 更像 |
|------|-----------|------|
| `0.04` | 急停 | **硬件** |
| `NOT W22.06` | 油温开关 | **硬件** |
| `NOT 0.11` | 空压机热保护断开 | **硬件** |
| `30.04` | 未命名联锁 | **查图纸（多半硬件）** |

动作：`W21.11` 出氧阀、`W21.05` 空压机等被复位 → 表现为整机停、阀关。

### 2.3 模拟量与“数值不对”（段：`_4AD数值`）

| 通道/寄存器 | 注释 | 排查 |
|-------------|------|------|
| 200 / D68 / D7 | 氧气纯度 | 分析仪、4–20mA、AD 量程、接线屏蔽 |
| 201 / D66 / D8、D9 | 空气压力 | 变送器、管路、AD |
| 202 / D65 / D11 | 氧气压力 | 同上 |
| 203 / D10 | 露点 | 露点仪 |
| D1–D4、D12–D21 | 上下限（多来自屏） | **软件设定**：上限/下限设反或过严会导致“假故障” |

### 2.4 执行机构不动作（段：`输出`）

程序有输出到 `100.xx` / `101.xx`（分子筛切换阀等）及空压机、电磁阀相关内部位。  
若 **PLC 输出灯亮、现场阀/电机不动** → **硬件**（继电器、接触器、阀体、气源）。  
若 **内部标志已置位但输出灯不亮** → 查联锁条件与段逻辑（软件条件未满足）。

## 3. 现场二分法：硬件 vs 软件

```
现象
 ├─ A. 一上电/一按启动就立刻停或根本不进入运行
 │     → 先查 0.04 急停、0.05 相序、0.11 热保护、H10.00 远程停、W21.09 两分钟保护
 │     → 输入灯与电气图不一致 = 硬件；输入正常但 W33/H10 仍置位 = 软件/屏/保持位
 │
 ├─ B. 能运行，过一会儿报警或停机
 │     → 盯 D9/D11/D62（压力纯度）、W22.06（油温）、W25.00
 │     → 实际压力表正常但 D9/D11 乱跳 = 变送器/AD（硬件）
 │     → 实际压力临界且屏上限下限很紧 = 设定（软件）
 │
 └─ C. 报警器响、阀不切换、空压机不转
       → 看 W25.00 / W21.05 / W21.11 与对应输出点
       → 输出灯亮执行器不动 = 硬件；标志不置位 = 联锁/设定（软件侧条件）
```

### 3.1 建议检测顺序（不停机能做的优先）

1. **看 PLC 输入指示灯**：0.04、0.05、0.11 在“应允许启动”时状态是否符合图纸（常开/常闭）。  
2. **触摸屏**：空气/氧气压力、纯度显示是否与就地仪表一致；核对上下限设定。  
3. **查保持位**：`H10.00` 远程停机是否被误置；报警解除 `W32.01` 是否可操作。  
4. **查输出**：空压机、出氧阀、分子筛阀对应输出点灯态 vs 现场动作。  
5. **仅当以上正常仍异常**：再考虑改逻辑/重下程序（需备份与停机窗口）。

### 3.2 处理对策速查

| 定位结果 | 处理 |
|----------|------|
| 急停回路断开/接线松 | 修按钮、安全继电器、线号；确认常闭串入正确 |
| 相序保护动作 | 查进线相序、相序继电器、电网缺相 |
| 空压机热保护 | 查过载、散热、复位；勿强行短接长期运行 |
| 油温开关 W22.06 | 查开关、油路、接线；确认常开/常闭与程序一致 |
| 压力/纯度数值漂 | 标定变送器、查 4–20mA、PLC AD 通道、接地 |
| 上下限过严 | 按工艺改屏参数（D 区相关设定），改前记录原值 |
| 远程停 H10.00 残留 | 屏上解除远程停；必要时按规程清除保持区 |
| 停机后 2 分钟内无法再启 | 属 `W21.09` 设计，等待或确认停机保护逻辑 |
| 30.04 等无名点动作 | 对照电气原理图找出该输入，按硬件联锁处理 |
| PLC 程序与柜内不一致 | 上载柜内程序存档，再与本工程比较（以现场运行为准） |

## 5. 推荐操作步骤（现场）

1. **备份**：本目录工程文件已精简，再整夹复制一份到 U 盘。  
2. **描述现象**：不能启动 / 运行中报警 / 压力异常 / 阀不动作（只选一类主现象）。  
3. **上电观察输入灯**：0.04、0.05、0.11 列表记录亮灭。  
4. **用 CX-Programmer 在线监视**（有线时）：`W21.00`、`W21.08`、`W25.00`、`W33.00`、`H10.00`、`D9`、`D11`、`D62`。  
5. **按第 3 节二分法** 归到硬件或软件设定。  
6. **只改一处**：先恢复硬件联锁，再动屏参数；改程序前上载柜内原程序。  
7. **试机**：启停各一次，确认报警可复归、急停有效。
