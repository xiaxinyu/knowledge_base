# 阶层与文化资本：韦伯、布迪厄与品味的再生产

> 「阶级」与「阶层」常被混用，「有没有中产」亦易沦为口号。马克思以生产关系界定经济位置；韦伯补上地位与权力；布迪厄再把文化资本、社会资本与**品味**纳入再生产机制。美国语境中的教材、词汇、剧集与运动，往往同时充当地位信号，而非中立消费品。
>
> 本文按一条可核对的链展开：**先校准概念 → 韦伯三轴与布迪厄三资本 → 语域与教育如何筛选 → 媒介与运动作为品味市场 → 中美流动（绝对 / 相对）→ 跨越、歧视与品牌含义**。可与 [51](./51-brand-cultural-translation.md)（品牌要占地位坐标）、[53](./53-li-ka-shing-capital-allocation-treatise.md)（经济形态转换）、[54](./54-ning-gaoning-talent-selection-treatise.md)（人如何被核验）对照。

先给一个直接答案：

> **阶级首先是经济位置；汉语里常说的「阶层」，多半指地位、荣誉、生活方式，以及布迪厄所说的文化与社会资本。** 美国社会的固化印象，相当程度上来自文化资本与品味的代际再生产：学校、语域、媒介与休闲把人分到不同符号轨道——开口用语、教材内容与被视为「正当」的兴趣偏好，往往已构成地位分类信号。中国近几十年**绝对向上流动**（子女整体高于父母）因高速增长而突出；**相对流动**（出身对归宿的约束强度）并非「全球最高」的简单断言——工业化抬高结构性机会，控制结构后近年队列多见相对流动性下降，部分指标与美欧接近，但整体是否仍高于美国随度量而异。经济意义上的「有产」跃迁可以较快完成；地位—品味—网络的跨越通常需要多代、多资本同步——仅积累经济资本而文化资本滞后，容易在符号秩序中被重新归入原位。品牌若不预先完成地位坐标选择，往往难以获得目标圈层的识别与接受。

**50-strategy 位置：** [51](./51-brand-cultural-translation.md) 写品牌如何跨文化少打折扣；本文写品牌所嵌入的**地位与品味秩序**本身如何被再生产。经济配置见 [53](./53-li-ka-shing-capital-allocation-treatise.md)；选人核验见 [54](./54-ning-gaoning-talent-selection-treatise.md)。

## 摘要

马克思以生产关系界定阶级；韦伯在《经济与社会》传统中区分 class（市场境遇）、status / Stand（社会荣誉与生活方式）、party（权力组织）三轴，反对把一切还原为单一经济切面。布迪厄在《资本的形式》与《区分》中把经济、文化、社会资本写成可互相转换的资源，并以习惯（habitus）与品味说明：审美判断分类事物，也分类判断者；文化资本又有具身、客观化、制度化三态。英语的日耳曼词根与拉丁／法语借词形成显著**语域差**——日常口语偏前者，学术与正式写作偏后者；教育阶段越高，拉丁语源词比例往往上升。学区财政与居住隔离、精英古典语传统、声望媒介与高门槛运动，则是品味市场的可见切片（须防把单一平台或族群刻板写死）。中美比较宜拆开绝对流动与相对流动：中国高速增长期绝对流动高；美国绝对收入流动从约 1940 年出生队列的九成左右降至 1980 年代出生队列的约一半；中国相对流动在控制结构后近年队列下降，与美比较仍可能阶段性更高但方向为收敛。跨越地位不是「一代暴富」的同义词。歧视既有可见侮辱，也有结构排斥——「顶层不存在歧视」属于过度概括。

**关键词：** 阶级；阶层；韦伯；布迪厄；文化资本；社会资本；品味；habitus；语域；社会流动；品牌定位

## 1. 读法与术语

全文只钉一句：

> **先分清「经济位置」与「地位—品味—网络位置」，再谈美国是否固化、中国是否「没有阶层」。** 混用概念，争论永远错位。

### 1.1 术语对照

| 术语 | 一句话 |
| ---- | ------ |
| **阶级（Marxist class）** | 主要由与生产资料的关系界定：有产 / 无产等；分析轴是经济与剥削结构。[^marx] |
| **阶级处境（Weberian class）** | 韦伯仍用 class：在市场中处置货物与技能以获取收入的典型机会；属**经济秩序**。[^weber] |
| **地位 / 身份群体（status, Stand）** | 社会荣誉、生活方式、消费礼仪所构成的群体；财富不等于荣誉。中文讨论里常被说成「阶层」的核心。[^weber] |
| **党派 / 权力（party）** | 为影响共同体行动而组织起来的权力追求；属政治／支配秩序。[^weber] |
| **文化资本** | 布迪厄：学识、认知、谈吐、审美性情等；一定条件下可兑经济资本；分具身／客观化／制度化三态。[^bourdieu-forms] |
| **社会资本** | 可持续的熟识与承认网络所承载的资源（「你认识谁、能调动谁」）。[^bourdieu-forms] |
| **习惯（habitus）** | 由阶级条件塑造的持久性情系统：如何感知、判断、举止。[^bourdieu-distinction] |
| **品味（taste）** | 对美丑、雅俗的偏好；「分类事物，也分类分类者」。[^bourdieu-distinction] |
| **绝对流动** | 子代整体是否高于父代（常随经济增长抬升）。 |
| **相对流动** | 出身对目的地的束缚强度（机会在多大程度上由出身决定）。 |

口语里 class / status 都会被叫做「阶层」；英语里也常混用 *class*。理论段尽量跟文献对齐；叙述段用「经济阶级 / 地位阶层」对照，减少歧义。

### 1.2 边界

1. **教学观察不是抽样调查。** 校园、流媒体、运动场上的轶事用于钉问题类型；外推全国须另做数据。  
2. **不把美国写成铁板、不把中国写成无阶层。** 两国都有结构约束与开放缝隙；差别在机制与历史阶段。  
3. **语言史有神话层。** *Ivanhoe* 式「农夫养 cow、贵族吃 beef」便于记忆，历史语言学更曲折——正文保留**语域分层**的硬核，弱化通俗故事的定年细节。[^cow-beef]  
4. **媒介与运动例子防写死。** Netflix 亦产「声望剧」、HBO 观众并不等于「上层全体」；篮球亦有天价经济层。谈的是**门槛与符号**，不是本质主义。  
5. **「顶层不歧视」不成立。** 公开辱骂可能更少；遗产录取、俱乐部、地理隔离仍是排斥。

## 2. 从马克思到韦伯：为何要分「阶级」与「阶层」

概念校准之后，先回答一个常见错位：为何「有钱」与「有地位」常常不同步？

马克思传统把阶级锚定在**经济**：谁占有生产资料、谁出卖劳动力。这一刀极锋利，也因此容易漏掉——同样收入的人，荣誉、生活方式与权力机会可以完全不同。[^marx]

韦伯的回应不是取消经济，而是坚持：权力在共同体内的分配是**多维的**。在 *Economy and Society* 的经典章节中，他区分三轴：[^weber]

| 轴 | 秩序 | 问的问题 |
| -- | ---- | -------- |
| **Class** | 经济 | 市场境遇与生活机会如何？ |
| **Status (Stand)** | 社会 | 荣誉、生活方式、谁与谁「门当户对」地来往？ |
| **Party** | 权力 | 谁能组织起来影响决策与人事？ |

三轴互相影响，但**不可互相还原**。韦伯特别强调：纯粹的「裸货币权力」并不自动等于社会荣誉——地位群体往往以特定**生活方式（style of life）**自我封闭，财富必须先被转译为被承认的消费与交往形式，才进入荣誉秩序。有钱却无「正当」生活方式，可能买得到商品、买不到圈子；有荣誉头衔却市场境遇下滑，也常见。

中文里常说的「没有中产」——若指马克思意义上「中产不是一个稳定的生产资料位置」，可以成立为理论判断；若指「社会不存在中间收入与中间地位群体」，则与经验不符。本文不介入口号之争，只要求一件事：

> **讨论美国「固化」时，多半谈的是地位—品味—网络，而不只是工资单。**

**所以 · 边界在哪：** 用马克思谈剥削结构，用韦伯谈荣誉与权力；不要把两个问题挤进一个词。下一节由布迪厄把「地位如何被日常标记与兑换」写得更可操作。

## 3. 布迪厄：三资本、习惯与品味

韦伯说明了「经济 ≠ 荣誉」；布迪厄进一步说明：位置靠什么资源维持，以及日常偏好如何把位置写进身体。他把资源写成可互相转换的**资本**，把偏好写成可观察的**品味**。[^bourdieu-forms]

| 资本 | 大致内容 | 制度化例子 |
| ---- | -------- | ---------- |
| **经济资本** | 钱与产权 | 财产权 |
| **文化资本** | 学识、认知、谈吐、审美性情 | 学历、证书 |
| **社会资本** | 关系与承认 | 头衔、门第、校友网络 |

文化资本本身还有三态，时间尺度不同——这也是「有钱却仍显『暴发』」的机制入口：[^bourdieu-forms]

| 状态 | 含义 | 为何难「速成」 |
| ---- | ---- | -------------- |
| **具身（embodied）** | 谈吐、姿态、感知方式；嵌在身体与时间里 | 须长期灌输与同化，无法二手转让（布迪厄强调：不能像买物一样委托别人替你完成） |
| **客观化（objectified）** | 书、画、乐器等文化器物 | 物可买；会不会用仍取决于具身能力 |
| **制度化（institutionalized）** | 学历等官方承认 | 把能力变成可比较、可兑换的资格；相对独立于持有者当下的「实际文化量」 |

**习惯（habitus）**把童年环境写进身体：什么觉得「自然」、什么觉得「俗」。[^bourdieu-distinction] 《区分》（*La Distinction*, 1979）的核心命题可收成一句：

> **品味分类事物，也分类分类者。** 对艺术、食物、衣着、休闲的偏好，标记并再生产社会位置。[^bourdieu-distinction]

产品语境里也有同构表述。Steve Jobs 在访谈中说：最终落在 **taste**——尽量接触人类做过最好的东西，再带进自己的工作。[^jobs-taste] 这句话谈的是创造；放在布迪厄透镜下，taste 从来不是纯天赋，而是长期暴露与教育的沉淀。品牌之间「最终差在品味」，与地位再生产属同一家族的问题——见 [51](./51-brand-cultural-translation.md)。

把同一骨架对准中美，经验内容不同，机制同构。西方资本主义发展时间更长，父母收入、学区与职业路径更容易相互咬合，**代际传递文化资本**的通道更稳定。中国近几十年收入跃迁极快，常见「经济资本先跳、文化资本滞后」——收入与谈吐、婚恋标准、审美习惯不对齐。这不等于「中国不存在阶层」，更准确的表述是：

> **高速增长打乱了三类资本的同步，错位更显眼。**

教学示意（非道德审判）：县城出身进入高薪技术岗后，婚恋与消费习惯仍可能按旧环境运行；城市中上层则更常把认知、表达与家庭背景放进匹配函数。外貌在不同社会空间权重不同——顶层也有外貌门槛，但稀缺的往往是**可被承认的文化与网络**，而不是单一的外貌军备赛。个体故事只能示意，不能代替分层数据。

**所以 · 边界在哪：** 布迪厄写的是法国调查年代的机制；搬到中美，要改经验内容，不必改「资本可转换、品味可标记」的骨架。下一节看两条最日常的再生产管道：语域与学校。

## 4. 语言与学校如何充当筛选器

文化资本如何从「理论」变成「一开口就被归类」？两条最日常的管道是：说什么话，上什么学。

### 4.1 英语的双层词库

英语大量并行词：日常、具象、口语一侧，历史渊源上偏**日耳曼**；正式、抽象、学术一侧，偏**拉丁／经法语借入**。研究显示，拉丁语源词在说明文、书面语与年龄增长后的文本中比例更高，初中到高中是清晰分界之一。[^register]

常被用来讲「阶层记忆」的动物／肉食词对——*cow / beef*、*pig / pork*、*sheep / mutton*——在通俗叙事里联系诺曼征服后的主仆分工；历史语言学指出：词义分化定型远比斯科特小说更晚、更曲折。[^cow-beef] **可保留的硬核不是那则童话，而是三条：**

1. 英语确实存在高低语域的词库分层；  
2. 学术考试与精英书写强化拉丁语源、抽象词；  
3. 母语者对语域错位极其敏感——用错正式度，会被快速归类。

更好的课堂例子是同义分工：*buy*（日耳曼）对 *purchase*（法语／拉丁路径），*help* 对 *assist*，*kingly* 对 *royal / regal*。[^register]

教学轶事须纠一句：**complex 与 complicated 二者皆属拉丁语源路径**，不是「一个日耳曼、一个贵族拉丁」。听者听不懂 *complex*、改口 *complicated*，说明的是**词汇广度与学术语域暴露不足**，或英语非母语的缺口——不宜写成「日耳曼词 vs 拉丁词」的证明。母语精英圈对语域的敏感，仍然成立。

### 4.2 学区轨道与古典语

语域筛选发生在口头；更硬的制度筛选发生在学区。美国公共教育高度依赖地方财政与学区边界：居住隔离把收入分到不同学区，财产税底座使富区与穷区的资源、同伴与选修结构长期分叉。Owens、Reardon 与 Jencks 等估计：有子女就读公立学校的家庭之间，**学区间收入隔离**在 1990–2010 年间上升超过约 15%；大型学区内校际（按免费午餐资格）隔离在约 1991–2012 年间上升超过约 40%。[^school-seg] 穷学区与富学区「看见的世界」不同，不是修辞，而是财政与空间机制。

精英预科与部分博雅传统强调拉丁语／古典语：语法训练、文本细读、与「正当」文化谱系对接。拉丁语作为**文化资本投资**，功能常是三条，而不是神秘地「提高智商」：

1. 进入学术英语与专业术语的词根系统；  
2. 训练形式化推理与文本纪律；  
3. 发出「我属于某一教育轨道」的信号。

大学若高度同质（同学来自同类高中），社会经济背景极端分化的同窗会显得统计学上罕见——这是筛选结果，不是偶然。中国大型公立学校里贫富同校更常见，并不等于地位再生产消失，而是**空间混合度更高**，文化资本落差会以别的方式显影（谈吐、补习、志愿与婚恋）。

**所以 · 边界在哪：** 语言与学校是地位再生产的重要一环，不是唯一环；法律、房产、税收与种族史同样关键。下一节把同一「区分」逻辑延到学校之外的休闲市场。

## 5. 媒介、运动与日常的品味市场

学校把人送上不同轨道；休闲则在轨道之外继续做区分。布迪厄之后，媒介研究常用「区分」读电视：HBO 以 *It’s not TV. It’s HBO* 把自己从「普通电视」划出，声望剧成为文化资本的展示场。[^hbo-distinction] Netflix 后来亦挪用声望话语（如 “TV Got Better”），说明平台标签会漂移——**不能把 Netflix≡下层、HBO≡上层写死**。[^netflix-distinction]

更稳的说法是：

> 市场供给不同**认知负荷、反讽密度与合法文化引用**的内容包；订阅者用选择做区分；价格与品牌叙事参与区隔，但不等于人口学一一对应。

教学观察：有人在家庭对话里把「看 HBO / 看 Netflix」说成品味分水岭；词汇量与笑点对不上，是文化资本落差的日常显影。个别订阅价格随套餐与年份而变，正文不钉死数字。

运动同理：高尔夫、网球、马术的场地与装备门槛高，从小系统训练需要持续现金与时间；篮球、足球进入成本相对低。结果是参与结构在统计上倾斜——**宜读作经济与组织门槛，不宜读作族群本质**。日常寒暄中的「你看什么运动？」常常同时探测可共同说话的世界与圈子边界。

**所以 · 边界在哪：** 品味市场帮助识别位置；把任何平台或运动写成种姓，会重新掉进本质主义。机制清楚之后，才能比较中美：流动「高」指的是哪一种流动。

---

## 6. 中美流动：绝对高不等于相对最强

「中国阶层流动全球最强」一类断言，需要先拆开两个量，再与经验体认对照。

| 概念 | 问的问题 | 中国常见图景 | 美国常见图景 |
| ---- | -------- | ------------ | ------------ |
| **绝对流动** | 子代整体是否高于父代？ | 高速增长期，大量子女收入／职业高于父母 | Chetty 等估计：约 1940 年出生队列中，约 **90%–92%** 子女收入高于父母；1980 年代出生队列降至约 **50%**[^chetty-mobility] |
| **相对流动** | 出身对归宿的束缚有多强？ | 工业化抬高结构性机会；控制结构后近年队列相对流动下降；与美比较仍可能阶段性更高，但远非无争议的「全球第一」[^xie-mobility] | 相对流动长期偏低且大致停滞的讨论很多；教育等指标上中美可接近[^wider-mobility] |

两层必须分开读。高速工业化会抬高**结构性**的向上流动（「上面的位子变多了」）；剔除结构之后，流动性是否开放，是另一张表。Xie、Dong、Zhou 与 Song（*PNAS*, 2022）指出：中国职业流动因工业化而上升，但**净掉工业化之后**的职业流动与教育流动近年队列下降；与美国同期比较仍可能更高（女性教育流动等例外），方向却是收敛而非「单向最强」。[^xie-mobility]

空间机制也不同：中国公立学校里贫富同校更常见；美国居住与学区隔离使「在同一走廊遇见极端贫穷」更难——这是机制差异，不能直接推出「中国无阶层」。

更公允的命题是：

> **中国近几十年让大批人完成经济阶级跃迁；地位与文化资本的对齐往往滞后。美国则更早把经济、学区、语域与品味连成一条更长的代际链，故「开口即被归类」的经验更为强烈。**

**所以 · 边界在哪：** 用绝对流动的经验感受否定相对固化，或用美国固化否定中国开放缝隙，都是以偏概全。下一节回答实践问题：若要跨越，跨越的是哪一种位置、需要多长时间。

---

## 7. 如何跨越：多代、多资本

概念与机制清楚之后，跨越问题才说得清——先分清跨越的是哪一种位置。

| 跨越 | 时间尺度（经验） | 常见路径 |
| ---- | -------- | -------- |
| **经济阶级**（无产→有产） | 一代内可能完成 | 创业、产权、稀缺技能溢价——失败率仍高，但时间尺度可以较短 |
| **地位阶层**（文化 + 社会 + 荣誉） | 常需多代累积 | 教育轨道、婚姻与网络、生活方式、公共表达的正当性 |

发达经济体里流传一种代际投资叙事：**自己学理工，子女学政法，孙辈学艺术史**——把经济安全垫在前代，把文化与符号正当往后移。宜作「策略素描」，不必当作可考证的出处。

关键机制与布迪厄一致：**任一资本长期短缺，其它资本的兑换率会恶化。** 只有钱而缺乏被承认的文化形式与网络，容易成为「暴发」标签的靶子；只有谈吐而没有经济与组织位置，则难持续。中国语境里「富二代跌回」的焦虑，常是文化资本与社会资本未同步——具身状态尤其吃时间，买一堆书（客观化）替代不了会用书的习惯。

实践含义是长期的：把暴露（书籍、旅居、严肃媒介、高质量同伴）当成与储蓄同等重要的家庭政策——不是一年看完布迪厄就能「升层」，而是改变下一代的习惯起点。

**所以 · 边界在哪：** 本文不提供速成「升层」方案；只说明资本种类与时间尺度不同。跨越讨论常被「歧视是否只发生在底层」打断——下一节拆开可见侮辱与结构排斥。

---

## 8. 歧视：可见侮辱与结构排斥

「顶层玩合作、只有底层才歧视」——作为气质描述，有时符合商圈经验；作为普遍命题，则过度概括。韦伯—布迪厄框架下，排斥不必表现为脏话；它更常表现为**谁被允许进入可兑换资本的场域**。

| 形态 | 更常见的显影 |
| ---- | ------------ |
| **可见侮辱** | 地域歧视、种族脏话、网络嘲讽——资源稀缺处，标签成为廉价的自尊武器 |
| **结构排斥** | 遗产录取、乡绅俱乐部、区划与警务差异、招聘「文化契合」——不必粗鲁，也能把人挡在门外 |

商人聚居的小区可能较少公开的地域贬损，因为共同游戏是交易；并不证明权力顶端没有排斥。美国精英对移民「不说脏话」与「是否愿意共享核心圈层」，是两件事：前者是礼貌规范，后者是社会资本与地位边界。

**所以 · 边界在哪：** 批评底层歧视的心理补偿功能，同时承认顶层排斥可以更礼貌、更有效。最后一节落到策略：品牌与沟通如何被同一套地位秩序约束。

---

## 9. 对品牌与沟通的含义

把 §2–§8 的机制收回到策略层：地位秩序如何约束品牌与说话。

1. **品牌必须自选地位坐标。** 不声明「给谁用、像谁、拒绝谁」，就会被市场随机归类——或更糟，被高文化资本圈层判为「不可携带」。见 [51](./51-brand-cultural-translation.md)。  
2. **沟通先侦察语域。** 对学术语域说话用日常词，会被判幼稚；对日常语域堆拉丁词，会被判装——这是 §4.1 的直接应用。  
3. **不必向所有品味做解释。** 布迪厄意义上，差评常常是位置的回声；把精力留给可共同游戏的人，是社交上的资本配置，不是道德冷漠。  
4. **中国阶段变化。** 温饱之后，社会学与哲学议题更容易进入公共讨论——文化资本从「听起来空」变成可交易、可炫耀、可继承的资产。这与 [52](./52-token-economics-treatise.md)「无法被廉价计量的判断才有剩余溢价」同向。

## 10. 收束

```text
  马克思：经济阶级
        │
        ▼
  韦伯：经济 × 地位荣誉 × 权力组织
        │
        ▼
  布迪厄：经济 / 文化 / 社会资本 → 习惯 → 品味
        │
        ▼
  ┌─────────────────────────────────┐
  │ 学校·语域·媒介·运动 = 筛选与标记 │
  └─────────────────┬───────────────┘
                    ▼
     绝对流动 ≠ 相对开放
     有产可快；地位常慢
```

一句话：**看清阶级与阶层的分寸，才能看清美国为何「开口即被归类」，以及中国的收入与品味为何经常不同步——也才能理解品牌与教育为何从来不只是功能问题。** 概念分清，机制才读得懂；机制读懂，策略才落得准。

---

## 11. 本章要点

1. **阶级 ≠ 阶层：** 前者偏经济生产关系／市场境遇；后者在汉语讨论里常指地位、荣誉与生活方式。  
2. **韦伯三轴：** class / status / party，互相影响，不可还原。  
3. **布迪厄：** 经济、文化、社会资本；文化资本有具身／客观化／制度化三态；品味分类者也被分类。  
4. **英语语域：** 日耳曼／拉丁分层是学术语域的真实机制；*cow/beef* 通俗故事宜降级；*complex/complicated* 不能当「日耳曼 vs 拉丁」例证。  
5. **学校：** 学区财政与居住隔离是美国教育轨道分化的制度底座；古典语是精英链条上的信号与词根训练。  
6. **媒介与运动：** 声望叙事与门槛制造区分；平台标签会漂移。  
7. **中美流动：** 中国绝对流动曾很高；美国绝对收入流动大幅下降（Chetty 等）；相对流动下降／收敛，不宜写成「全球最强」或「中国无阶层」。  
8. **跨越与歧视：** 有产可一代、地位常多代；可见侮辱与结构排斥分层处理；品牌要自选地位坐标，沟通先侦察语域。

## 12. 参考文献

[^marx]: 马克思、恩格斯传统中的阶级分析：以生产关系与生产资料占有为核心范畴。教学表述从简；细读《资本论》与相关阶级理论文献。

[^weber]: Max Weber, *Economy and Society* 中 “Class, Status, Party”（德文 *Klassen, Stände, Parteien*）一章。Class 在经济秩序，Stand 在荣誉／社会秩序，Party 在权力。英译常见 Gerth & Mills 选本；亦有 Waters 等较新译文讨论 *Stand* 译法。

[^bourdieu-forms]: Pierre Bourdieu, *The Forms of Capital*（英语常见于 Richardson 编 *Handbook of Theory and Research for the Sociology of Education*, 1986）。经济、文化、社会资本及其转换；文化资本的具身、客观化、制度化三态。

[^bourdieu-distinction]: Pierre Bourdieu, *La Distinction*（1979；英译 *Distinction: A Social Critique of the Judgement of Taste*）。品味、习惯与阶级位置；「taste classifies, and it classifies the classifier」。

[^register]: 英语语域与词源：Bar-Ilan & Berman 等关于拉丁语源／日耳曼词源随文体与年龄变化的研究；学术英语中 Graeco-Latin 词汇与抽象度的讨论。用于支持「教育阶段越高，正式拉丁语源词越密」，不是种族或智商叙事。

[^cow-beef]: 关于 *cow/beef*、*pig/pork* 的通俗诺曼故事与历史语言学纠正：Walter Scott *Ivanhoe* 的文学定型；当代词源与中世纪英语研究指出词义分工定型更晚、更复杂。正文取其「符号记忆」，不取其作为 11 世纪制度史铁证。

[^school-seg]: Ann Owens, Sean F. Reardon, Christopher Jencks, *Income Segregation Between Schools and School Districts*, *American Educational Research Journal*, 2016：有子女就读公立学校的家庭之间，学区间收入隔离约 1990–2010 上升超过约 15%；大型学区内校际（免费午餐资格）隔离约 1991–2012 上升超过约 40%。Owens 后续工作进一步讨论学区间隔离与成绩差距。用于机制说明，不展开全部州际差异。

[^hbo-distinction]: HBO 声望剧与区分话语：如 “It’s not TV. It’s HBO” 品牌史；McCabe/Akass 等关于 quality TV 与文化正当化的讨论。

[^netflix-distinction]: Tryon 等关于 Netflix 挪用声望／区分话语（如 “TV Got Better”）的分析——说明流媒体标签会争夺「正当文化」位置，而非固定阶层容器。

[^jobs-taste]: Steve Jobs 访谈（如 PBS *Triumph of the Nerds* 相关转录流传）：*Ultimately, it comes down to taste… expose yourself to the best things that humans have done…* 用于产品与品味，本文借以对接布迪厄，不引申为乔布斯研究布迪厄。

[^chetty-mobility]: Chetty, Hendren, Grusky, Hell, Manduca, Narang 等，*The fading American dream: Trends in absolute income mobility since 1940*, *Science*, 2017（及 Opportunity Insights / NBER 版本）。基准估计：约 1940 年出生队列绝对收入流动约 92%，1984 年出生队列约 50%。

[^xie-mobility]: Yu Xie, Hao Dong, Xiang Zhou, Xi Song, *Trends in social mobility in postrevolution China*, *PNAS*, 119(7), e2117471119, 2022。职业与教育代际流动：工业化抬高结构性机会；控制结构后近年队列相对流动下降；与美国同期比较仍可能更高（女性教育流动等例外），方向为下降／收敛而非「单向全球最强」。

[^wider-mobility]: UNU-WIDER 等工作论文对中美教育／社会经济流动的比较：强调绝对与相对之别；中国相对流动历史更高但下降、与美国指标收敛等判断随数据与度量而异，正文取审慎表述。
