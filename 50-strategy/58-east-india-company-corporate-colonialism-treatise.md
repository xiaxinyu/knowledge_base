# 东印度公司：特许贸易公司如何吸收主权职能

> 十八世纪末，英国东印度公司（East India Company, EIC）在南亚维持约二十万量级的武装力量——可与当时英国本土常备陆军相比，甚至更大；并具备法庭、货币与行政机器，行使征赋、开战、缔约与地方人事等职能。其法律身份却始终是特许股份公司：有董事会、有股东、须分红。问题因而不是「商人何时变坏」，而是：**在利润与帝国竞争的目标函数下，贸易组织如何一步步吸收国家职能。**
>
> 可与本库 [13](../10-chronicle/13-world-hegemony-transfer-chronicle.md)（霸权与公共品）、[53](./53-li-ka-shing-capital-allocation-treatise.md)（特许权与形态转换）、[46](../40-paradigm/46-systems-thinking-philosophy.md)（反馈与锁定）对照。本文提供历史机制案例，不是投资建议，也不是民族史裁判。

先给一个直接答案：

> **EIC 并未在某一天「决定征服一个国家」。** 护航武装与设防商馆积累武力；1757 年普拉西确立附庸政治；1765 年孟加拉 **Diwani**（赋税权）使采购成本从公司账上被税入掩盖，汲取进入核心业务；军队—税收—再扩张形成正反馈。内部异议多为风险—回报计算，而非伦理刹车。有效约束来自外部主权：议会立法、财务危机与舆论丑闻，以及 1857 年后的国家接管——1858 年行政权归王室，1874 年法人注销。可迁移的治理命题有三：**渐进越界难中途叫停；受益方难以自我约束；「成本从账上消失」往往只是成本外化。**

**50-strategy 位置：** [50](./50-ai-industry-disruption-strategy.md) 写产业穿透；[55](./55-global-manufacturing-migration-chronicle.md) 写制造地理；本文写**特许公司如何吸收主权职能**。

## 摘要

1600 年获特许的英国东印度公司，起初经营远东贸易垄断；经海上武装、商馆设防与政治谈判筹码的积累，于 1757 年普拉西之役后扶植附庸纳瓦布，又在 1764 年布克萨尔之役后、于 **1765 年**获得孟加拉、比哈尔与奥里萨的 Diwani，完成从「运银买货」到「以税购货」的质变。[^dalrymple-2019][^nam-plassey] 公司军（主体为印度籍士兵 sepoys）在十八世纪末约二十万、十九世纪初约二十五万量级，长期大于同期英国本土常备陆军的通行叙述规模。[^nam-armies][^dalrymple-2019] 约 1769–1770 年孟加拉大饥荒死亡极重：旱灾与疫病为直接触发，税收压力、军粮与救济不足等为广泛讨论的加剧因素——宜作复合因果。[^bengal-1770] 议会以 1773 年《规制法》、1784 年皮特《印度法》等逐步加套；1857 年大起义后，**1858 年《印度政府法》**移交王室统治，公司行政终结，法人于 **1874** 年解散。[^uk-parliament-eic] 叙事按「贸易武装 → 税收权 → 军税正反馈 → 机制规律 → 外部约束 → 当代启示」展开。

**关键词：** 东印度公司；普拉西；Diwani；公司军；孟加拉饥荒；渐进越界；成本外化；外部约束；特许权；公司国家

## 2. 贸易武装：护商如何军事化

**1600** 年，公司获伊丽莎白一世特许状，取得对东方贸易的垄断权（此后特许多次续展与重组，细节从略）。早期模式清楚：白银与欧洲商品运出，香料、棉布、硝石、茶叶等运回。[^britannica-eic]

武装化来自三件可自我合法化为「保护贸易」的业务决策：

| 步骤 | 当时的理由 | 累积后果 |
|------|------------|----------|
| **船要装炮** | 远洋数月；海盗与荷、葡等竞争者海上冲突常见；一船货值巨大 | 公司具备海上武力投射 |
| **商馆要设防** | 囤货与银钱需要围墙与守卫；加高、加员每次都是小决定 | 岸上据点军事化 |
| **谈判要筹码** | 经商许可、关税、特权须与当地统治者谈；有兵与无兵，话语权不同 | 商业谈判与武力胁迫边界模糊 |

到此为止，组织自我理解仍是「护商」。转折不在某一纸「征服宣言」，而在政治—军事机遇与孟加拉财政入口的打开——下一节。

**所以 · 边界在哪：** 护商武装是远洋贸易时代的常态（荷属东印度公司等亦然）；质变要等到**税收权**，不是第一门炮。

## 3. 税收权：从采购到汲取

### 3.1 普拉西（1757）：胜负不全在战场

**1757 年 6 月 23 日**，罗伯特·克莱武（Robert Clive）率领的公司军在普拉西（Plassey）对抗孟加拉纳瓦布西拉杰·乌德-道拉（Siraj ud-Daulah）。纸面兵力上，公司方远居少数（通行叙述约三千人对数万）；胜负关键在政治安排：纳瓦布军中主将米尔·贾法尔（Mir Jafar）被事先收买，阵前按兵不动，公司得以以极小伤亡取胜，并扶植米尔·贾法尔为新纳瓦布。[^nam-plassey]

这一仗确立的是**附庸政治**：商业公司开始决定谁坐地方统治者的位子。

### 3.2 布克萨尔与 Diwani（1764–1765）：质变之年

更关键的财政节点在普拉西之后约八年。**1764** 年布克萨尔（Buxar）之役巩固军事优势；**1765 年 8 月 12 日**，莫卧儿皇帝沙·阿朗二世（Shah Alam II）授予公司孟加拉、比哈尔与奥里萨的 **Diwani**（赋税征收权）——公司由此进入帝国财政官僚链条，而不仅是特许商人。[^diwani-1765][^nam-plassey]

| | 此前 | 此后 |
|--|------|------|
| **现金流** | 从英国运白银采购 | 用当地税收在当地采购，再运欧销售 |
| **账上「成本」** | 采购支出显明 | 采购可用税入覆盖，公司报表上的「进货成本」逻辑被改写 |
| **业务性质** | 贸易价差 | **汲取 + 贸易**：利润绑定土地支配权 |

威廉·达尔林普尔（William Dalrymple）等叙述强调：1765 年前后，公司从常规国际贸易公司，变为「披着商人外衣的殖民权力」。[^dalrymple-2019] 埃德蒙·伯克后来抨击其为「伪装成商人的国家」（*a state in the disguise of a merchant*）——点的正是身份错位。[^burke-eic]

### 3.3 1770 年饥荒：复合因果，不是单行判决

约 **1769–1770** 年孟加拉大饥荒，死亡规模在史学中常被引为数百万量级（有叙述至约千万，估计区间争议大，正文不锁死单一数字）。作物歉收与疫病是直接触发；公司侧因素被广泛讨论的包括：税收仍紧、军粮采购、粮商行为与救济有限，以及「双重行政」（公司掌财、纳瓦布残存民政）下的治理失灵。[^bengal-1770]

**纠偏：** 不宜写成「公司单独制造了饥荒」的法庭判决；宜写成——**在汲取型财政刚成型时，冲击吸收能力极差，政策选择加重了人道灾难。** 成本从公司采购账上「消失」之后，并未消失，而是压在土地与人口上。

## 4. 军税循环：扩张为何对股东划算

养兵极贵，但在扩张阶段，军队对股东更像**收入引擎**而非纯成本中心：多控制一片地区 → 多一份税收 → 税收覆盖军费并有余 → 能养更多兵 → 再控制更多地区。这是正反馈。[^nam-armies]

| 量级（通行叙述） | 说明 |
|------------------|------|
| 十八世纪末约 **20 万** | 三大管区军（孟加拉、马德拉斯、孟买）合计；主体为印度籍士兵 |
| 十九世纪初约 **25 万** 量级 | 国家军队博物馆等叙述「大于许多国家的陆军」 |
| 与英国本土陆军对比 | 常见对照是：公司军一度可达本土常备陆军的约两倍量级——精确年份与编制口径不同，宜作数量级印象[^dalrymple-2019] |

伦敦董事并非从不反对前线开战：战争风险高，败则损失落股东。但反对理由往往是 **「不划算」**，不是 **「不正当」**。下一场仗的预期回报率一高，反对声就弱。整个组织里，与「收敛」绑定的位置很少——前线致富、股东分红、帝国战略间接受益，构成同向激励。

```mermaid

  A["武力 / 政变筹码"] --> B["控制与条约"]
  B --> C["税收 / Diwani"]
  C --> D["以税购货 + 分红"]
  D --> E["扩军"]
  E --> A
```

## 5. 机制层：三层规律

史实之上，可抽出三条可检验的组织动力学命题（启发式，不是历史铁律）：

### 5.1 改变规则的回报高于规则内竞争时，组织会去改规则

在规则内竞争：压成本、提效率、抢客户，利润有上限。若能拿到**定价权、税收权、许可权**，收益换量级。以利润（及帝国竞争）为硬考核的组织，在岔路口的选择高度可预期——驱动的是**目标函数**，不必诉诸人格突变。

### 5.2 过程渐进，故难在中途喊停

武装商船 → 设防商馆 → 常驻军队 → 干预继承 → 征收赋税：每步距离小，每步有「护商 / 稳定 / 自保」话术。没有哪一天召开「征服印度」启动会。路径依赖一旦形成，整套业务建在汲取上，回撤等于自我清算。

### 5.3 内部治理管不住有利可图的越界

股东受益，董事会看回报，前线私囊与地方权力一齐膨胀。内部「风控」若考核仍挂在扩张与利润上，功能上只是副驾。**有效约束多半来自不从该业务直接分红的外部权力**——见下节。

**所以 · 边界在哪：** 上述三层需要特许垄断、军事真空、母国相对纵容等条件同时在场；不可外推为「一切公司必将殖民」。

## 6. 外部约束：立法与国家接管

约束来自英国议会与舆论。动机是复合的：**道德语言、公司破产风险、战争债务，以及不能容忍私人公司掌握超主权军队**缠在一起——不宜简化为「良知觉醒」。[^uk-parliament-eic]

| 节点 | 内容 |
|------|------|
| **1773 《规制法》** | 议会首次系统干预公司印度事务：孟加拉总督（总督）与行政委员会、加尔各答最高法院等；背景含治理丑闻与公司财务危机[^regulating-1773] |
| **1784 皮特《印度法》** | 设枢密院「印度事务监督委员会」（Board of Control），政治军事受制于政府，商业仍归董事部——双重控制[^pitt-1784] |
| **此后特许续展** | 贸易垄断逐步被撕开；公司愈发像「受托管的行政机器」 |
| **1857 大起义** | 公司军与政治秩序遭受体系性冲击 |
| **1858 《印度政府法》** | 印度统治职能转归王室，开英属印度（Raj）直管时代；公司丧失行政权[^uk-parliament-eic] |
| **1874** | 公司法人由议会法案正式解散[^uk-parliament-eic] |

它主要是被**外部主权关掉行政外壳**，不是在产品市场上被竞争对手淘汰出局。

## 7. 对当代组织的三条启示

从历史迁移到当代，只借**激励与约束结构**，不借「你就是东印度公司」的道德指控。

### 7.1 渐进越界比一次性越界更难叫停

一次性大幅越权会触发警觉与抵制；若每次只推进一小步且均有 KPI 话术，中途难形成否决联盟。待业务已建在越界路径上，回撤成本往往高于继续向前。

**自检：** 过去数个季度的「例外审批」，是否已固化为默认流程？

### 7.2 受益方难以充当有效刹车

若负责人、团队、上级与考核指标均从扩张受益，体系内部很难产生真实制约。风控若奖金仍挂增长，功能上仍是副驾。刹车须来自**不从该业务直接取酬的人**——独立董事、监管、审计、客户用脚投票，或硬性合规红线。

### 7.3 警惕「成本从账上消失」

Diwani 之后，采购成本被税入掩盖，真实负担转到土地与人口。机制类比（非历史等同）：把成本转嫁合作方、下游、公共资源或另一部门的考核——报表改善，全成本仍在。承担方退出或崩溃时，系统才暴露真实费用结构。

| 历史节点 | 机制类比 |
|----------|----------|
| 护商武装 | 以「交付安全」不断扩张权限边界 |
| 扶植附庸 | 以灰色手段锁定渠道与规则 |
| Diwani | 成本外化、利润内化 |
| 议会接管 | 外部监管与牌照风险兑现 |

> 没有哪一天它「决定征服一个国家」。它是在每一个决策点选择了回报率更高的选项，并在两百年里把选项累积成路径。

## 8. 本章要点

1. EIC 法律上是特许股份公司，事实上长期行使战争、税收与行政等国家职能。  
2. 质变节点是 **1765 Diwani**，不是第一门舰炮；普拉西是政治—军事门槛。  
3. 「以税购货」改写商业模式：利润绑定支配权，汲取进入核心。  
4. 军—税正反馈解释超大规模公司军；内部反对常是风险偏好，不是伦理刹车。  
5. 1770 饥荒宜作复合因果；汲取型财政放大冲击。  
6. 有效约束来自议会与国家接管；1858 行政终结，1874 法人注销。  
7. 可带走：渐进越界、受益者难自刹、成本外化三戒——用于治理设计，而非道德影射。
