# 五百年霸权转移：荷兰、英国、美国与当代过渡

> 近五个世纪，资本主义世界体系中的领导权大体经历了荷兰 → 英国 → 美国的接力；每一次接力都伴随着商业—金融组织方式的升级、海权与财政能力的重组，以及（自十八世纪以降）工业革命对生产可能性的改写。霸权不是「谁兵力最多」的单一奖牌，而是提供开放市场、关键货币、危机最后贷款人与安全秩序等**国际公共品**的能力——金德尔伯格（Kindleberger）提醒：当旧霸权已弱、新霸权不愿出手时，体系会坠入漫长动荡。
>
> 今日处在美国仍居体系中心、同时面临多极叙事、公共品意愿争议与第四次工业革命叠加的过渡期。2020 年代中后期的新讨论强调两类风险并行：一是「多极已成」的过度宣称；二是**反向金德尔伯格陷阱**——守成国收缩供给意愿，崛起方又尚无能力承接美元与全球安全公共品，体系落入金融与秩序的「空窗 / 间歇」。历史顾虑不是「谁必然接棒」，而是**过渡期本身的失序成本**。可与本库 [55](../50-strategy/55-global-manufacturing-migration-chronicle.md)（制造业地理迁移）、[10](./10-computing-cloud-chronicle.md)–[12](./12-artificial-intelligence-chronicle.md)（技术史）对照：霸权是秩序与公共品，工厂迁移是产能节点，技术编年是工具底座。

先给一个直接答案：

> **荷兰（约十七世纪高峰）**靠商业共和、航运、金融与东印度公司网络成为早期现代商业—金融霸权；**英国（约十九世纪高峰，尤其 1815–1914）**靠财政—金融国家、海权、自由贸易帝国与第一次工业革命成为工业—金融霸权；**美国（约 1945 年后高峰）**靠世界大战后的生产能力、美元—布雷顿森林制度、同盟体系与第二 / 三次工业革命成果成为军事—生产—货币复合霸权。**当代**并非已完成「下一次正式交棒」，而是美国相对优势变化、中国等力量上升、区域化与第四次工业革命并行的**过渡与竞争期**——多极话语很响，但军事—货币深度网络效应仍大幅偏向美国；同时美国供给全球公共品的意愿波动，使空窗风险上升。趋势是：霸权空间尺度扩大、组织复杂度上升、物质扩张后期常伴金融化、技术竞赛从烟囱转向芯片—算力—标准。历史顾虑是权力过渡期的体系动荡（1929–1939 是惨痛先例），以及把「修昔底德陷阱」当成必然战争剧本的简化。

**10-chronicle 系列导读：** [10](./10-computing-cloud-chronicle.md)–[12](./12-artificial-intelligence-chronicle.md) 写计算、信息与智能的技术史；[14](./14-internet-history-chronicle.md) 写协议与入口。本文是**世界领导权 / 霸权转移的五百年编年**：先立概念与理论透镜，再按荷—英—美展开时间、原因与标志事件，嵌入四次工业革命，最后写当代过渡与历史顾虑。产能地理见 [55](../50-strategy/55-global-manufacturing-migration-chronicle.md)，产业穿透见 [50](../50-strategy/50-ai-industry-disruption-strategy.md)——两篇都是节点与护城河，不是公共品交棒。

## 1. 如何读「霸权」：定义、透镜与边界

### 1.1 本文所说的「霸权」是什么

在国际关系与世界体系文献里，**霸权（hegemony）**通常不是日常口语里的「霸道」，而是：某一国家（或国家—资本复合体）在特定历史阶段，对**国家间体系**行使领导与治理功能的能力——其权力部分来自实力，部分来自其他国家认为其领导「也符合更普遍利益」的认可。[^arrighi-heg]

金德尔伯格从大萧条研究中提炼的实践含义是：稳定的世界经济需要领导者提供一组**国际公共品**。他强调的稳定功能常被概括为：为过剩商品开放市场、提供逆周期长期贷款、在危机中充当贴现窗口 / 最后贷款人、维持相对稳定的汇率体系，并协调宏观政策。[^kindleberger] 十九世纪英国与二战后美国常被当作履行（或部分履行）这些功能的范例。

霸权因此至少有三层：**(1) 物质能力**（生产、财政、军力）；**(2) 网络与标准**（货币、支付、科技协议）；**(3) 意愿与合法性**（是否愿意支付公共品成本、他者是否接受）。三者不必同步——当代许多争论，正出在「能力仍强、意愿波动」或「局部能力上升、全球公共品供给不足」。

### 1.2 常用透镜（各有用处，皆非定律）

| 透镜 | 代表 | 核心主张 | 使用时注意 |
| ---- | ---- | -------- | ---------- |
| **体系积累周期（SCA）** | 乔瓦尼·阿瑞吉 *The Long Twentieth Century* | 近数百年资本主义经历热那亚—荷兰—英国—美国等周期；每周期常经物质扩张 → 金融扩张 → 体系动荡与领导权再集中 | 热那亚 / 伊比利亚可作前史；勿把阶段年表当成精确日历 |
| **霸权稳定论（HST）** | 金德尔伯格、吉尔平等 | 开放稳定的国际经济秩序往往需要一个愿意且有能力的霸权 | 「需要霸权」≠「霸权永远仁慈」；合作与制度也可部分替代 |
| **权力转移理论** | Organski 等 | 崛起国接近守成国时，体系战争风险上升 | 欧洲史归纳强；「修昔底德陷阱」是通俗标签，不是必然律 |
| **资本主义通史** | 米歇尔·波德 *Histoire du capitalisme 1500–2010* | 从萌芽、扩张、危机写到全球化：资本如何塑造秩序、不平等与周期性崩溃 | 与阿瑞吉互补：波德更贴生产方式与阶级；本文主线仍是公共品霸权，不以波德替代金德尔伯格 |

阿瑞吉与西尔弗（Silver）还强调：荷兰→英国、英国→美国的过渡，常伴随**体系混乱（chaos）与治理再造**，而不是平滑的行政交接。[^arrighi-silver]

**前史一句：** 阿瑞吉谱系常把热那亚金融资本与伊比利亚扩张作为更早的积累中心。西班牙白银不等于资本主义，见第 2.3 节；主线仍按荷兰—英国—美国展开。

### 1.3 边界：本文写什么、不写什么

- **写**：荷兰、英国、美国三次主导性现代霸权的时间窗口、原因、标志事件；四次工业革命与霸权形态的对应；当代过渡、多极辩论与地缘技术趋势；历史顾虑。西班牙前史（金银不等于资本主义）见第 2.3 节；波德通史口径嵌在第 2、3、5、7、9 节，不另起一套年表。产能地理与四次大迁移见 [55](../50-strategy/55-global-manufacturing-migration-chronicle.md)，本文只取与公共品霸权相交的接口。  
- **提及但不展开**：热那亚 / 葡萄牙殖民年表的逐次战役。  
- **不写成**：中国「已经」或「必将」接棒的预言；也不写成美国「已经结束」的讣告。当代是**证据竞争中的过渡期**，且专业文献本身存在尖锐分歧（见第 9 节）。

### 2.2 贯穿五百年的几条趋势

1. **空间尺度扩大：** 从北海—波罗的海—亚洲贸易网络的荷兰，到全球殖民与自由贸易的英国，再到全球同盟与美元流动性的美国——领导权所覆盖的地理与制度半径总体变大。  
2. **组织复杂度上升：** 从特许公司与交易所，到财政—国债—央行国家，再到布雷顿森林机构、多边联盟与全球价值链治理。  
3. **物质扩张之后常出现金融化：** 阿瑞吉强调，当生产与贸易的利润空间收窄，资本更倾向流动性与金融扩张；这既是「成熟」，也常是「下一场混乱」的前兆。[^arrighi]  
4. **技术底座改写霸权武器：** 蒸汽与铁路强化英国；电力、石化与流水线强化美（德）工业；电子与信息强化美国晚期优势；人工智能、网络、生物技术与关键矿产正在改写当代竞赛维度（见第 8–9 节）。  
5. **交棒很少「签字交接」：** 更常见的是长期相对衰落 + 新兴中心崛起 + 战争或大危机加速旧秩序解体。  
6. **能力与意愿可以脱节：** 1929 年是「旧者不能、新者不愿」；当代讨论则出现「旧者仍能、但愿否不稳；新者渐能局部、却尚不能全局替代」的变体。  
7. **积累可以与生产方式脱节：** 金银流入、殖民租金或金融扩张，都不自动等于可持续的资本主义生产组织。西班牙是前史（第 2.3 节）；后来霸权周期里的金融化，是同一结构的变体。

### 2.3 前史：金银不等于资本主义

1492 年之后，西班牙占尽先机：美洲土地、强制劳动与金银矿带来巨额流入。波德提醒：**巨额财富不等于资本主义。** 征服与掠夺可以堆出宫廷与贵族的富，却不一定堆出可自我增殖的生产方式。教学上可从四头看缺口：美洲财富集中于少数贵族与冒险家，国内不平等随殖民加深；人口仍主要在农村，而不是集中在贸易城市；生产仍以农业与行会手工业为主，大规模商业交换不是多数人的日常；财政靠向农民收租，而不是靠工商业税基养活国家。结果是：四处掠夺，商业税收仍赶不上占领与战争的开销。**1588** 年无敌舰队战败，势力范围被压缩——发现美洲的先行者从此错过把白银写成资本主义体系的窗口。[^beaud]

主线仍从荷兰写起：荷兰才把远程贸易、信用与海上力量拧成可复制的组织。西班牙这一节只用来钉死一句——**掠夺是积累的一种来源，不是霸权的可持续形态。**

## 3. 荷兰霸权：商业—金融共和国的高峰

### 3.1 时间

- **常用窗口：** 「荷兰黄金时代」约 **1588–1672**（有的文化史叙述更宽，至十八世纪初；政治—军事转折常以 **1672 灾难年**为象征）。  
- **体系位置：** 在沃勒斯坦（Wallerstein）《现代世界体系》第二卷等叙事中，荷兰常被视为现代世界体系中**第一个真正的霸权国家**；阿瑞吉则将其作为热那亚周期之后的重要体系积累周期。[^wallerstein-dutch]  
- **相对衰落：** 十七世纪后期起，英荷竞争加剧；十八世纪英国在财政—军事国家能力上逐渐压过荷兰，尽管荷兰金融与商业专长仍长期外溢。

### 3.2 原因（为何是荷兰）

1. **商业共和与城市网络：** 联省共和国权力相对分散，商人精英与城市利益深度嵌入国家决策，利于贸易导向政策。  
2. **航运与中转优势：** 低地国家地处西北欧贸易交叉口；航运技术、造船与大宗商品中转（谷物、木材、香料、纺织品等）形成网络效应。安特卫普在十六世纪的衰落与封锁，客观上助推阿姆斯特丹崛起。  
3. **金融创新：** **1609 年**阿姆斯特丹银行（Wisselbank）成立，常被当作近代中央银行的重要前驱；公共债务市场与证券交易所使资本动员与风险分担领先于多数欧陆君主国。[^voc]  
4. **特许公司与海外网络：** **1602 年**荷兰东印度公司（VOC）成立，常被当作早期股份公司与殖民贸易公司的典范——把远程贸易、武力与资本聚合在同一组织里；西印度公司（WIC / GWC）则面向大西洋。  
5. **相对的宗教宽容与人力资本：** 吸引工匠、商人与受迫害的少数群体流入，强化商业城市的人才密度（程度因城市与时期而异，不宜浪漫化成「全面自由」；殖民暴力与奴隶贸易同属荷兰扩张的黑暗面，不可从「黄金」叙事中抹去）。

### 3.3 标志性事情

| 年份 / 时段 | 事件 | 意义 |
| ----------- | ---- | ---- |
| **1602** | VOC 成立 | 公司化远程贸易与早期股份融资 |
| **1609** | 阿姆斯特丹银行 | 支付与信用基础设施 |
| **十七世纪** | 阿姆斯特丹成为欧洲金融与商品定价中心 | 汇票、证券、大宗商品 |
| **1652–1654 / 1665–1667 / 1672–1674** | 第一、二、三次英荷战争 | 商业—海权正面冲突 |
| **1672** | 「灾难年」（Rampjaar） | 法、英等多重打击；黄金时代转折象征 |
| **1688** | 光荣革命 | 奥兰治的威廉入主英国；荷兰金融—军事经验外溢 |

光荣革命不是「荷兰征服英国」的简单故事，却是**荷兰金融、军事与政治经验向英国财政—军事国家建设外溢**的关键节点。

### 3.4 历史顾虑（荷兰留下的）

小国可以凭借网络与金融成为霸权，但**国土纵深与人口上限**使其在全面战争与大陆均势中脆弱。荷兰的教训是：商业—金融领导权若缺少可持续的财政—军事国家升级，终将被更大的领土—财政国家超越。另一面教训是：领先者的资本与人才会流向追赶者——见第 4 节。

### 3.5 波德口径：三根支柱与权力摩擦

波德把荷兰的高峰写成三根支柱：**1602** 东印度公司对荷兰亚洲航线的特许垄断；阿姆斯特丹银行掌握兑换与支付枢纽；重型舰队撑起「海上马车夫」。商人资本家与银行资本家支配大宗贸易、组织商会，阿姆斯特丹一度是世界金融中心。[^beaud] 这与第 3.2 节不冲突，只是把组织钉得更紧。VOC 垄断的是荷兰东印度贸易特许，不是欧亚全部远程贸易。

他同时指出一个难以调和的摩擦：新兴资产阶级有财富，却未必握有足够的国家权力；与奥兰治派 / 执政结构一旦顶牛，资本主义生产方式就难以在全国铺开。十七世纪后半叶与英、法开战，军费超出国力，又赶上西欧衰退与殖民地商品跌价——财力充实的资产阶级开始负债，繁荣逐渐成为历史。联省是共和国，不宜简化成「王室打压商人」；更准确的是**商人寡头、执政家族与战争财政之间的错位**。第 4 节英国的对照正在这里：光荣革命把资产阶级、议会与财政信誉拧到同一套国家机器上。

## 4. 从荷兰到英国：制度差异与资本外溢

世界体系与制度史研究强调：荷兰与英国的霸权**不是同构复制**。

| 维度 | 荷兰 | 英国 |
| ---- | ---- | ---- |
| 国家形态 | 更偏分权的商业共和国 | 更强的集中财政—金融国家 |
| 霸权底座 | 贸易网络、航运、金融中介 | 国债—央行—海军—工业—帝国 |
| 赶超逻辑 | 率先创新 | 国家主动干预以追赶荷兰 |
| 资本流向 | 荷兰投资者大量持有英国资产 | 吸收领先者资本加速自身崛起 |

荷兰投资者投资于英国，部分原因正是：荷兰政府无力也不必阻止资本流向回报更高之处；两国宪制不同，资本外溢通道畅通。[^dutch-to-british]

这种「领先者的资本养活后来者」的现象，在后来的霸权周期中反复出现——也是当代讨论「资本外流 / 产业外移」时的长历史回声。

光荣革命后的英国，逐步具备：议会对财政的约束与信誉、央行与国债市场、皇家海军扩张——合称财政—军事国家（fiscal-military state）的升级。没有这一步，第一次工业革命的领先也难以转化为全球霸权。

## 5. 英国霸权：工业、海权与自由贸易帝国

### 5.1 时间

- **崛起期：** 十八世纪至拿破仑战争结束；**1815 滑铁卢 / 维也纳会议**之后，英国进入欧洲均势下的全球海权优势期。  
- **高峰常用窗口：** **约 1815–1914**，史称 **Pax Britannica**（不列颠治世）——并非天下无战争，而是英国海军与金融在全球贸易航线上的主导地位相对稳固。  
- **相对衰落信号：** 十九世纪末美德工业追赶、1873 年后长期萧条压力、殖民地行政成本、一战财政与人力耗竭；到 1918 后已难单独提供全球公共品。

### 5.2 原因（为何是英国）

1. **财政—金融国家：** 国债市场与英格兰银行（**1694**）支撑长期战争与海军开支，信誉成为竞争力。  
2. **海权：** 控制关键海峡与殖民地节点，保护贸易并强制开放市场。  
3. **第一次工业革命：** 约 **1760 年代起**在棉纺织、煤炭、蒸汽机、铁与机器制造上领先，使英国成为「世界工厂」的前序形态（与本库 [55](../50-strategy/55-global-manufacturing-migration-chronicle.md) 中后来的世界工厂叙事衔接）。它不是「欧洲自文艺复兴以来已全面领先」的收束，而是把十八世纪多极均势写成工业霸权的奇点。人口不及法国一半的岛国如何点火，见第 8.2.3–8.2.5 节。  
4. **自由贸易转向：** **1846 废除谷物法（Corn Laws）**等标志英国从重商保护转向单边自由贸易倡导——以工业优势换取全球市场开放。  
5. **金本位与伦敦金融城：** 英镑与伦敦货币市场成为十九世纪国际贸易与投资的清算中心。  
6. **正式帝国与非正式帝国并行：** 正式殖民地与通过资本、海军、治外法权维持的影响力并存。

波德把上述条件收成**三波依次叠加的红利**，见第 5.3 节；五台引擎（煤铁、劳动力、贸易、专利、工匠与科学）见第 8.2.3 节。

### 5.3 三波红利（波德）

西班牙与荷兰先后错过把先发优势写成可持续资本主义的窗口；偏居海岛的英国抓住了。波德强调：不是单一天才，是三个时期做对了选择，红利逐级叠加。[^beaud]

1. **重商主义（约十六世纪末—十七世纪上半叶）。** 国家以工商为本，可随时干预或支持。**1588** 年后海洋主导权打开，殖民扩张与全球贸易做大实业：东印度公司这种半商业半军事混合体，在亚洲铺开据点；北美殖民地形成运输渠道。与西班牙不同的是，殖民地财富被用来喂贸易和工商业，殖民与资本主义互相促进。  
2. **自由与宪制约束绝对王权（十七世纪）。** 资产阶级财富增加后，要寻求国家权力的保护，与绝对王权冲突。荷兰卡在权力摩擦上；英国则经历内战与 **1688** 光荣革命，把王权关进议会与财政信誉的笼子。洛克的《政府论》（Two Treatises of Government）从社会契约讲政府合法性，强调被统治者的同意——不宜写成卢梭式「公意」。资产阶级既借民众运动限制王权，又与部分贵族谨慎妥协。经济自由成为贸易与生产再飞跃的催化剂。  
3. **领土扩张 + 工业革命（十八世纪后半叶起）。** **1756–1763** 七年战争从法、西手中夺走大批殖民地，贸易与生产循环跟进。工厂成为资本主义生产的核心组织：圈地把分散条田、公地转为可买卖的农场，释放劳动力进入矿井与制造；煤炭喂饱蒸汽，棉纺织带动煤铁。殖民统治、世界贸易、商业资本主义与工业资本主义交汇。节点年份（瓦特 1769 / 1776、工厂制）与第 8.2 节同读，不必另记「1780 年改良」为唯一开端。

至此英国在十八世纪末成为欧洲工业与海权的领先者；「世界霸主」的制度性高峰，仍以 **1815–1914** 的 Pax Britannica 为常用窗口（第 5.1 节）。

### 5.4 标志性事情

| 年份 / 时段 | 事件 | 意义 |
| ----------- | ---- | ---- |
| **1694** | 英格兰银行成立 | 战争融资与财政信誉 |
| **约 1760–1840** | 第一次工业革命展开 | 蒸汽、纺织、工厂制、铁路前奏 |
| **1805 / 1815** | 特拉法加；滑铁卢 | 海权与反拿破仑胜利 |
| **1846** | 废除谷物法 | 自由贸易转向的象征 |
| **十九世纪中后期** | 金本位实践深化 | 伦敦为世界银行家 |
| **1873–1896** | 长期萧条（Long Depression） | 英国相对工业优势收窄的前奏；垄断组织与海外争夺升温 |
| **约 1880–1914** | 新帝国主义与美德竞争 | 霸权仍在，工业优势收窄 |
| **1914** | 第一次世界大战爆发 | Pax Britannica 解体加速 |

### 5.5 长期萧条（1873–1896）

一说起大萧条，许多人只想到 **1929–1933**。波德要读者先看见更早的一串：**1873–1895/96** 席卷欧美的长期萧条。史学上常称为 Long Depression，是一连串危机的家族，而不是单一事件；方向是第二次工业革命把钢、铁路、电力、化工产能推上去，利润变薄，同质化竞争迫使企业合并，卡特尔与托拉斯出现，垄断资本主义抬头。国内市场消化不了过剩，必须向海外找出路；农民、手工业与落后产业被挤压，海外民族运动也使市场不再任由工业国予取予求。这串压力，构成 1914 年大战的经济前史之一——不是唯一导火索，但是导火索上的一段药线。[^beaud] 与第 8.3 节「美德赶超」同读。

两个转折值得单独钉住。

1. **英国慢慢失去全球经济支配地位。** 波德转述的数量级：煤炭从「比德、美合计还多」落到一战前约只有美国的一半；世界工业生产份额从约 1870 年的三成上下落到一战前的一成五左右；全球贸易从约 1880 年的四分之一落到 1913 年约六分之一。口径与 Bairoch 等制造业份额估计（第 8.2.4 节给的是英国上升段）并不逐项重合，**方向**与第 8.3 节美德赶超一致：英国份额下降，美国上升。正文只取方向，不作两套表的法庭对账。  
2. **工资劳动者与城镇人口成为体系变量。** 完成工业化的国家里，工薪阶层与城镇人口上升，有组织、有诉求。激进论者把他们写成资本主义的掘墓人；波德更模棱——问题再大，也常逼出调整：实际工资上升、劳动时间缩短、社会保障立法出台。动荡有所平复，欧美主要国家没有在这场长期萧条里崩盘；逐利惯性与市场的内在矛盾并未被取消。第 6 节 1929 年的空窗，正是调整用尽、公共品真空叠加上去之后。

### 5.6 历史顾虑（英国留下的）

工业领先可以被追赶；海权需要持续财政。更深刻的顾虑是：当霸权国自己的工业优势被侵蚀，却仍用金融与帝国租金维持生活水平时，**物质基础与金融表象会脱节**——这正是阿瑞吉所说金融扩张阶段的危险感。对后来者：追赶者可以在「第二代工业」上跳跃；对守成者：免费提供公共品的意愿会随相对衰落而下降。

## 6. 过渡失序：1914–1945 与「英国不能、美国不愿」

两次世界大战之间的世界经济，是理解「霸权转移为何可怕」的核心课时。它的前史是第 5.5 节的长期萧条：英国相对份额已在下滑，垄断与海外争夺已升温；1914 年之后，缺的是愿意提供公共品的继任者。

金德尔伯格的经典判断：十九世纪到 1913 年前后，英国大致扮演了体系稳定者；**1929 年大萧条之所以如此深、如此广，不是因为冲击本身史无前例地大，而是因为世界体系不稳定——英国已经不能扮演稳定者，美国则还不愿意。** 原句常被引为：*"In 1929, the British couldn't and the United States wouldn't."*[^kindleberger]

### 6.1 标志性事情

| 年份 / 时段 | 事件 | 意义 |
| ----------- | ---- | ---- |
| **1914–1918** | 第一次世界大战 | 欧洲秩序与金本位重创；美国成债权国 |
| **1919** | 凡尔赛体系 | 政治安排与经济复兴脱节 |
| **1929** | 华尔街崩溃与大萧条 | 公共品真空的实验室 |
| **1931** | 英镑脱离金本位 | 金融恐慌跨国传染 |
| **1933** | 伦敦世界经济会议失败 | 国际宏观协调破产 |
| **1930 年代** | 以邻为壑关税、集团化、再军备 | 秩序碎片化 |
| **1939–1945** | 第二次世界大战 | 旧帝国坍塌；美国生产机器定胜负结构 |

### 6.2 本段的核心历史顾虑

霸权转移的最大风险往往不在「新霸权多么坏」，而在**旧者已无力、新者尚未愿**的空窗期。权力转移理论强调崛起方接近守成方时的战争风险；金德尔伯格则补充：**即使没有「注定的争霸战」，公共品真空本身足以制造灾难。** 第 9 节将说明：今日讨论中出现了这一公式的**镜像变体**。

## 7. 美国霸权：生产、货币与同盟体系

### 7.1 时间

- **能力积累：** 十九世纪末已成工业产量第一强国之一；一战与二战使其债权与生产地位不可逆上升。  
- **制度性霸权确立：** **1944 布雷顿森林**、**1945 战后安排**、**1947 马歇尔计划**、**1949 北约**——美国开始系统提供安全、市场、流动性与重建资金。  
- **两极中的西方霸权：** 冷战期间，全球是美苏两超；在资本主义世界体系内部，美国是无可争议的领导。  
- **「单极时刻」：** 约 **1991 苏联解体后**至二十一世纪初，美国相对优势达到近代峰值之一。  
- **相对挑战加剧：** **2008 全球金融危机**、长期战争消耗、制造业外包争议、中国崛起与技术竞争——进入「仍居中心、但公共品成本与意愿受质疑」的阶段。

### 7.2 原因（为何是美国）

1. **大陆纵深与资源—移民国家：** 统一市场、资源禀赋与持续移民带来的规模。  
2. **两次大战的生产动员：** 「民主国家兵工厂」把工业能力转化为体系领导权。  
3. **美元与布雷顿森林—美元体系：** 先是美元—黄金，后是后布雷顿森林的美元信用与国债市场深度。  
4. **同盟与前沿存在：** 北约、双边同盟、海外基地网络降低盟友安全自助成本，也锁定美国领导。  
5. **科技与高等教育：** 第二、三次工业革命中的关键创新与人力资本（半导体、航空、软件、互联网等）强化长期优势。  
6. **意识形态与制度输出：** 多边机构、贸易规则与发展叙事（程度随时期变化，且常与利益捆绑）。

### 7.3 标志性事情

| 年份 / 时段 | 事件 | 意义 |
| ----------- | ---- | ---- |
| **1913–1914** | 福特流水线与「5 美元工作日」 | 管理革命的教学节点：连续装配 + 高工资短工时 |
| **约 1930** | 美国集中世界黄金储备的很大一块 | 金融中心从伦敦转向纽约的物质前奏 |
| **1944** | 布雷顿森林会议 | IMF、世界银行框架；美元中心 |
| **1947** | 杜鲁门主义与马歇尔计划 | 安全承诺 + 欧洲复兴 |
| **1949 / 1950–53** | 北约；朝鲜战争 | 冷战前线化 |
| **1971** | 尼克松冲击 | 美元停止兑换黄金——形态变，非霸权终结 |
| **1989–1991** | 东欧剧变与苏联解体 | 单极时刻开启 |
| **1990–2000 年代** | 全球化高潮 | 美元流动性扩张 |
| **2001 / 2008** | 「9·11」与长期战争；全球金融危机 | 能力与合法性承压 |
| **2018 以降** | 贸易—技术冲突；疫情供应链政治化 | 地缘经济显性化 |

### 7.4 与制造业迁移的接口

产能接力与公共品接力不是同一条轴。[55](../50-strategy/55-global-manufacturing-migration-chronicle.md) 的教学框架是：**二十世纪初美国接英国 → 五十年代日本崛起 → 七十年代亚洲四小龙接日本 → 八十至九十年代起中国接四小龙并成为「世界工厂」。** 迁出的是劳动密集环节，不是制造业归零；美、日、德在高端与标准上仍居关键位置。东亚梯度可用赤松要「雁行形态」解释，解释不了荷—英—美谁提供市场、货币与安全。

美国将组装与低端环节外移、保留品牌—标准—金融，既延长了价值链顶端地位，也削弱部分国内生产共同体对「继续支付霸权成本」的政治支持——**金融—科技精英的全球化收益**与**中位选民的产业安全感**之间的张力，成为当代美国政治的主轴之一。当代再配置是 China+1 / 近岸，而不是再出一个单极世界工厂：双边贸易上的「去中国化」快于增加值脱钩。旗号换了，权力网络未必换。

### 7.5 波德三因：管理、金融、科技

一战后欧洲相对下降，美国跃为第一经济强国；让全世界认同其引领作用，仍要等到二战之后的制度安排。波德把美国如何重塑资本主义收成三因，与第 7.2 节并列，不互相替代。[^beaud]

**（1）管理革命。** 1920 年代美国并未忙于再铺一套旧式殖民帝国，而是深耕国内市场、巩固加拿大与拉丁美洲后院。科学管理与连续生产从屠宰场拆解线走到福特汽车：**1913** 年前后 Highland Park 把流水线做成连续装配；**1914** 年「5 美元工作日」把日工资抬到约 5 美元、工时压到 8 小时量级。出厂价从千美元量级落到约三百美元；全美汽车年产量升至 **1929** 年约五百万辆。电气动力大量取代人力与蒸汽。这套大规模工业生产方式被世界效仿，影响到后来的经济全球化格局。数字是教学数量级，精确车型价格与产量以公司史与产业统计为准。

**（2）金融霸权。** 二十世纪上半叶世界黄金流向美国；约 1930 年美国黄金储备常被记到四十亿美元量级、约占世界四成——金融中心从伦敦转向纽约。二战后布雷顿森林：美元钉黄金，他国货币钉美元。美元作为结算货币，使美国得以用国债与美元流动性把部分调整成本外溢——这是铸币税与网络特权，**不是**「永远不用平衡财政」的定律。1971 年黄金窗口关闭后，美元仍靠经济、军力与市场深度维持中心地位。学术界常见判断：美国经济总量超过英国之后，美元主导还滞后数十年，并被两次大战加速。人民币若要在储备与结算上接近这一位置，经济总量只是必要条件，网络、法治与安全承诺都不是自动跟随。

**（3）科技创新。** 能源、材料、机械动力之外，波德特别看重电子化；当代则延伸到半导体与 AI。这与第 7.2 条第 5 点、第 8.4–8.5 节是同一条链：科技把生产优势写成可更新的权力。2010 增订把周期收到金融危机之后：三因能重塑资本主义，并不能取消崩溃。

## 8. 四次工业革命：技术底座如何改写霸权形态

从远古简单机械，到蒸汽轰鸣、电气闪耀，再到计算机普及与人工智能崛起，两百余年的近代工业演进，不止是技术迭代，更是**生产力、生产组织与全球权力格局**的改写。人类历经四次工业革命，一步步从手工劳作走向数字化、智能化；不同国家也走出各具特色的工业化道路——而这些道路，正是第 3–7 节荷兰之后英、美接力，以及第 9 节当代竞赛的物质底座。

克劳斯·施瓦布（Klaus Schwab）在世界经济论坛语境下普及的分期，便于把技术史接到霸权史上。需标明：这是**通行教学分期**，史学界对「第几次」「起止年」仍有争议；「第四次」是否独立于第三次数字化，亦有争论。[^schwab] 下表先给总览，随后按前史 → 1.0–4.0 → 多元道路展开。

| 工业革命 | 约略时期 | 关键技术 / 组织 | 与霸权的粗对应 |
| -------- | -------- | ---------------- | -------------- |
| **前史** | 远古—十八世纪中叶前 | 杠杆、齿轮、水力 / 畜力机械；动力长期受限于人力、畜力、水力 | 尚未形成「世界工厂」式工业霸权；机械智慧为近代工业积淀 |
| **第一次（1.0）** | 约 1760–1840 / 十九世纪中期 | 水力 / 蒸汽、机械纺纱、工厂制、早期铁路与汽船；有机经济转向矿物能源 | **英国**工业领先的物质基础；「大分流」放大；「世界工厂」前序 |
| **第二次（2.0）** | 约 1870–1914（延伸至二十世纪前期） | 电力、钢、化工、内燃机、流水线、电话 | **美德追赶**；美国在产量与企业组织上崛起；英国相对工业优势收窄 |
| **第三次（3.0）** | 约二战后—二十世纪末（半导体高潮自 1960/70 年代以降） | 原子能、电子计算机、空间技术、自动化与电信 / 互联网 | **美国**在信息与军民两用技术上巩固晚期优势；冷战两极与战后复兴多元 |
| **第四次（4.0）** | 约二十一世纪（WEF 2015/2016 起广泛讨论；仍处演进） | 物理—数字—生物融合：AI、物联网、云计算、增材制造等 | **竞赛开放**：算力、芯片、数据、标准与关键矿产成为权力变量 |

施瓦布强调第四次与第三次的差异在于**速度（指数而非线性）、广度（几乎所有行业）与系统冲击（生产、管理、治理整体改写）**。[^schwab]

### 8.1 前史：古代机械与动力短板

在近代工业到来之前，人类已积累大量机械智慧。远古时期，杠杆、车轮、滑轮、斜面、螺旋等简单机械即投入生产建设：古埃及建造金字塔利用滚木搬运巨石；阿基米德螺旋提水装置，常被当作后世螺旋输送机的思想雏形。古代中国同样贡献诸多技术创造：东汉**水排**借助水力鼓风炼铁，运用齿轮与连杆机构；晋代**连磨**以一头牛驱动多台磨盘，体现齿轮系的高效应用。中世纪欧洲出现脚踏车床、曲轴研磨机；十三世纪以降机械钟表逐步发展，连杆、齿轮、凸轮等机构被广泛研究；至达·芬奇时代，大量经典机械构型已被探索出来。

这一阶段的关键限制是：**动力主要依靠人力、畜力与水力**。机构可以精巧，能量密度与稳定性却长期不足——第 8.2.2 节所说的有机经济天花板。工业革命首先打破的，正是这条动力与能源边界。

### 8.2 工业 1.0：蒸汽驱动与机械化

**时间（教学常用）：** 约十八世纪六十年代—十九世纪中期。

要懂它怎么改写了世界，先懂它从哪起步。十八世纪前，纺靠手纺车，织靠木梭：一个人一天织不了多少像样的布。**1733** 年约翰·凯（John Kay）的飞梭让织布明显加快，「纺」反而成了瓶颈。随后几代人在纺纱机上接力：珍妮纺纱机、阿克莱特（Richard Arkwright）水力纺纱机、克朗普顿（Samuel Crompton）骡机。约 **1764/1765**，哈格里夫斯的珍妮机常被当作棉纺织机械化的标志性开端之一；**1769** 年瓦特改良蒸汽机；**1776** 年前后，博尔顿—瓦特机开始进入矿井与工厂。[^ir1-nodes] 关键不在某一台机器，在「动力可以昼夜不停」这件事：产量不再被人力与天气封顶。棉纺只是开头。蒸汽随后开进煤矿、铁矿、磨坊，再进入火车与轮船。手工工场转向机器大工厂；炼铁与机床体系完善。富尔顿的蒸汽汽船、史蒂芬森的蒸汽机车，改写运输成本并拉开世界市场。

约 **十九世纪中叶**，英国成为第一个完成工业革命的国家，并坐稳「世界工厂」位置。数量级见第 8.2.4 节：份额因产值、煤铁、棉纺织等口径而异，宜作**数量级判断**，不作精确法庭数字。[^ir1-britain] 技术随后扩散至法国、美国、德国，资本主义世界分工初步成形。

这些节点都对。但若只记住珍妮机与蒸汽机，会漏掉更关键的认知修正：**第一次工业革命不是欧洲自文艺复兴以来一路领先的水到渠成，而是把十八世纪多极均势写成十九世纪欧洲（首先是英国）工业霸权的历史奇点。** 下面分五步：先问 18 世纪欧洲是否已经「更厉害」，再问它到底改写了什么，然后问为何是英国、数字有多猛、同一时刻为何不是大清。

#### 8.2.1 18 世纪并非欧洲「一路领先」

常见倒果为因是：「后来欧洲先发生工业革命，所以工业革命之前欧洲一定已经全面领先。」近几十年全球史——尤其是**加州学派（California School）**——把比较单位从「欧洲 vs 中国整块」改成**核心区对核心区**，图景就不同了。[^pomeranz]

| 维度 | 加州学派 / 全球史口径 | 不宜推多远 |
|------|----------------------|------------|
| **生活水平** | 彭慕兰（Kenneth Pomeranz）比较约 1750 年英格兰与长江三角洲：预期寿命、消费与要素市场并不构成欧洲单极领先；关键是比「最发达对最发达」，不是拿西北欧去比整个清帝国。[^pomeranz] | 计量国民核算常把人均产出分叉前移到约 **1700** 年前后；彭慕兰本人后来也接受分叉或可早到十八世纪中叶。艾伦（Robert C. Allen）等实际工资序列显示，十八世纪中叶英格兰工资已明显高于长江三角洲。分歧在「何时拉开」与「用哪项指标」，不是「十九世纪中叶才出现任何差距」。[^great-divergence-metrics] |
| **制造业** | 十八世纪远程贸易里最抢手的制成品，仍是印度棉布、中国丝绸与瓷器。英国棉纺织机械化，很大程度是对印度棉布优势的**进口替代**：禁令（Calico Acts 等）保护国内市场，再以机器压低成本。[^asian-manufactures] | 棉纺织的「被碾压后回应」解释得通，不宜写成整场工业革命都是「亚洲逼出来的被动发明」。铁、煤、蒸汽、机床另有矿山排水与能源约束等动力。 |
| **军事技术** | 16–18 世纪若干中西冲突——**1521 屯门之战**（明 vs 葡萄牙）、**1685–1686 雅克萨之战**（清 vs 俄国，后接 1689 尼布楚条约）——并不是「欧洲一上岸就降维打击」。[^tunmen-yaksa] | 质的优势在 **19 世纪中叶前后**变得不可逆：第一次鸦片战争时蒸汽辅助炮舰（如 Nemesis）已参战，后装枪与工业动员随后跟上。铁甲舰（约 1860 年起）是放大，不是起点。把军事霸权推迟到「有了铁甲舰才算」会偏晚。 |

因此，更稳妥的表述是：十八世纪的旧大陆仍是**多极高位均衡**——欧洲、中国、印度各擅胜场，谁也不拥有后来那种跨领域代差。后来拉开的，是工业革命之后的生产可能性、能源基础与军事工业复合体，而不是文艺复兴已经写好的剧本。

> **教学提醒：** 时间轴宜画成「18 世纪多极均势 → 中间变量（第一次工业革命）→ 19 世纪欧洲工业—海权崛起」。不要用「后来领先」证明「从来领先」。

#### 8.2.2 重要在哪：陷阱、能源与「如何发明」

教科书列发明清单没有错；真正被低估的，是它改写了人类经济的三道约束。

**（1）打破马尔萨斯陷阱。** 工业革命之前，技术进步带来的剩余，往往被人口增长吃掉，人均生活水平长期锁在低位循环。工业革命之后，技术革新速度持续超过人口增长，人均收入才出现可维持的上升。这是经济史上的「现代经济增长」入口，不是多了几台机器那么简单。[^malthus-escape]

**（2）从有机经济转向矿物能源。** 里格利（E. A. Wrigley）把工业革命之前的经济称为**有机经济（organic economy）**：粮食、纤维、木材、畜力都依赖当年光合作用与土地面积，增长有天花板。煤炭是地质年代储存的太阳能；蒸汽机把这份存量变成可调度的热与机械功。瑞士的水力、荷兰的风力可以做功，但本质仍是即时自然力，受地理与气候约束，跳不出有机经济的流量上限。[^wrigley-energy] 彭慕兰则补充：英格兰煤炭易开采，加上新大陆「幽灵地亩」（ghost acres）提供纤维、糖与粮食，使西北欧逃出欧亚核心区共同面临的土地压力。[^pomeranz]

**（3）把发明变成可预期的过程。** 此前技术突破大量依赖工匠经验与偶然。此后出现莫基尔（Joel Mokyr）所说的**工业启蒙**：有用知识、实验与市场、资本结合起来，创新从偶发事件变成可投资、可管理、可加速的流程。第二次、第三次、第四次工业革命都站在这个「元发明」上——不是蒸汽机本身可无限复制，而是「如何系统地发明」可被后来者学会。[^mokyr-enlightenment]

#### 8.2.3 为何是英国：五台引擎

同样的机器，别国也能造。为何偏偏英国先点火？不是因为「英国人更聪明」或「更会做生意」——这两句都不算错，但没说到根上。真正让革命落在这座岛上的，是一组条件恰好凑齐。十八世纪中后期，大不列颠人口大约不到法国的一半（教学常用：英伦三岛合计约八九百万量级，法国约两千五百万上下），后来却在煤、铁与棉布上占到全球极高份额。少一台引擎，工业革命都可能换个地方出生。

| 引擎 | 内容 | 文献位置 |
|------|------|----------|
| **（1）煤铁相邻** | 煤矿边上就是铁矿，挖出来的煤直接炼铁；煤层浅、水运近，能源与原料在脚下凑齐。别处也有煤铁，很少像英格兰这样运费低到能养得起蒸汽。艾伦强调**高工资 + 便宜煤**诱导节省劳动的机器 | 彭慕兰；艾伦[^allen-britain]；里格利[^wrigley-energy] |
| **（2）被赶出土地的人** | 圈地运动把大量农民从公地挤走，工厂得到一支可雇佣的自由劳动力。听来残酷，却是工厂制的人口前提。不宜写成「圈地=全部工人」：人口增长与农业改良同样释放人手 | 与第 5 节社会基础衔接；劳动力来源是组合，不是单因 |
| **（3）海外贸易攒下的本钱** | 殖民与海上贸易送来金银、原料与海外市场：棉花来自帝国网络，布匹卖回海外。工厂的轮子靠全球贸易喂饱。国债、银行与伦敦货币市场，为运河、工厂与发明扩散提供资金 | 第 5.2 节；彭慕兰「幽灵地亩」[^pomeranz] |
| **（4）愿意保护发明的制度** | **1624** 年《垄断法》（Statute of Monopolies）把专利从王室恩赐拉向可预期的法律权利；光荣革命后财政信誉与产权预期改善，长周期投资更敢下注。一个工匠的发明，能变成受法律保障的收益 | 与第 4–5 节财政—军事国家衔接 |
| **（5）科学与工匠拧在一起** | 皇家学会与满手老茧的技工，在咖啡馆和工坊里碰头。理论的人与干活的人把想法变成机器——莫基尔所说的工业启蒙 | 莫基尔[^mokyr-enlightenment] |

这些条件在欧陆或东亚并非处处空白，但很少以同一组合、同一时间出现。历史判断宜写成：**不是命定，也不是纯运气**——偶然的是组合，可追问的是每种条件做了什么。

#### 8.2.4 数量级与社会账单

光说「很厉害」不够，看数量级——且都是估计，口径随作者而异。

贝罗克（Paul Bairoch）对世界制造业产出份额的经典估计：英国约 **1750 年 1.9%**，**1830 年 9.5%**，**1860 年约 19.9%**。一百年里，从几乎可以忽略，涨到接近全球五分之一。[^bairoch-share] 「占世界一半的煤、铁、棉布」是十九世纪中叶通行的数量级说法，精确百分比随产业而变，正文只取「领先且份额极高」。[^ir1-britain]

煤更夸张：约 **1700** 年英国年产煤两三百万吨量级，**1850** 年涨到约五千万吨；同一时期生铁产量翻了不止一个数量级。棉布是另一面镜子：一台蒸汽织机顶得上许多手工织工；英国机制棉布便宜到，后来能冲进印度市场——一个千年纺织核心区，被机器布改写分工位置。这与第 8.2.1 节「进口替代」是同一条链的后半段：先挡住印度棉布，再把成本压到能反向出口。[^asian-manufactures]

账不能只算一面。机器转在最前面的，是工人。失地农民进了城市，住进拥挤的贫民窟；工厂一天常干十二三个小时，童工被送进矿井与车间。他们生产了全世界的布，自己却未必穿得起体面的衣。城市排污跟不上人口，霍乱跟着涨。早期工业城市一边堆出财富，一边堆出苦难。**任何一场腾飞，账单都不会平摊。** 最先被机器碾过的，往往是地位最低的那批人。这是工业革命的另一面：不必回避，也无需夸大——它就在那儿。工厂法、矿井法与公共卫生改革，是事后补上的制度，不是开场就有的福利。

#### 8.2.5 同一时刻，为何不是大清

十八世纪，中国的经济总量仍然很大。按一些估算，约 1750 年前后中国仍占世界产出的很高比重，人口是英国的数十倍，丝绸、瓷器、茶叶行销全球。工业革命却没在这儿发生。差别不在「聪不聪明」，在几处结构——且必须与第 8.2.1 节同读：对照的不是「盛世只是虚火」，而是**有机经济里的繁荣，尚未拧成矿物能源上的工厂制**。

1. **科举不问技术。** 选官考经义文章。最聪明的人往「怎么写策论」上使劲，才华很少流向「怎么造机器」。英国那套学者 + 工匠的组合，当时没有对等土壤。  
2. **重农抑商的排序。** 商人在社会地位上靠后，资本更愿买地、放债，不愿冒开矿建厂的风险。不是没有商人，是剩余被引向土地与功名，而不是固定资本。  
3. **市场被拆得太碎。** 度量衡、货币、关卡不一，货从南运到北，税和费能剥掉几层。统一的国内大市场迟迟没长成蒸汽工厂所需要的那种规模。  
4. **一口通商与朝贡心态。** 当英国在海上织贸易网时，清中叶对外贸收束为广州一口，对外部技术大体关着门——不是「完全没有海贸」，是制度把能人的才华往功名与内陆秩序上引，而不是往远洋与机器上引。问题不在「有没有能人」，在**能人的才华往哪流**。

所以：一个社会把人的聪明往哪引，就会长成什么样。英国赶上了，别处没赶上，差别在结构，不在人种，也不在脾气。当代中国能造高铁、造芯片、造全球很大一部分钢，根子上的逻辑与两百年前同构——让技术被需要、让发明被保护、让市场连成一片——那是产能与工业化故事，**不等于**第 9 节所说的霸权交棒。

**与霸权的接口：** 没有蒸汽—工厂—铁路这一套物质基础，第 5 节的财政—海权—自由贸易帝国难以成立。「世界工厂」是生产优势；开放市场、英镑清算与海军护航才把优势写成霸权。两套坐标系并存：有机经济里的繁荣，与矿物能源经济里的新生产函数，到十九世纪才变成不可逆的权力差距。

### 8.3 工业 2.0：电力普及与电气化

**时间（教学常用）：** 约十九世纪七十年代—二十世纪初（组织创新延伸更久）。

蒸汽动力渐渐无法单独满足城市、交通与连续生产的需求；电力与内燃机登上舞台，开启电气时代。**1866** 年前后，维尔纳·冯·西门子（Werner von Siemens）等路径上的发电机工程成熟；此后数十年，电灯、电话、汽车、飞机相继进入产业与日常生活。**1886** 年卡尔·本茨（Karl Benz）取得汽油动力三轮车专利，戈特利布·戴姆勒（Gottlieb Daimler）等推动四轮汽车实用化。内燃机普及带动石油开采与石油化工扩张。生产组织迎来变革：福特 **1913** 年前后把流水线做成连续装配（节点与数量级见第 7.5 节），规模经济与标准化装配成为第二代工业的组织符号（与本库 [55](../50-strategy/55-global-manufacturing-migration-chronicle.md) 美国「世界工厂」叙事衔接）。

生产与资本不断集中，垄断组织出现，资本主义进入垄断阶段。这次革命中，**美国、德国实现对英国的工业赶超**：约十九世纪末至二十世纪初，美国在多项工业产量 / 产值指标上跃居世界前列（中学教材常记 **1894** 年产值第一，史学上宜按指标与年份分读）；德国成为欧洲头号工业强国之一。世界殖民地被列强瓜分完毕，资本主义世界体系在空间上「闭合」。机械领域，渐开线齿轮等传动理论落地，为大功率高速机械传动提供条件。

**与霸权的接口：** 英国仍握海权与金融至 1914 前后，但**工业物质优势已向美德倾斜**——第 5.6 节「物质基础与金融表象脱节」正由此起；第 7 节美国霸权，则建在第二次工业革命的规模、能源与企业组织之上。

### 8.4 工业 3.0：计算机、自动化与信息时代

**时间（教学常用）：** 第二次世界大战后—二十世纪末（电子与自动化高潮自 1960/70 年代以降更清晰）。

二战催生并加速大量前沿技术。通行概括常以**原子能、电子计算机、空间技术、生物工程**等为核心簇。**1946** 年 ENIAC 问世后，计算机经历电子管、晶体管、集成电路、大规模集成电路等代际迭代（细节见本库 [10](./10-computing-cloud-chronicle.md)、[12](./12-artificial-intelligence-chronicle.md)）。CAD 等计算机辅助设计软件兴起，手工计算与图解设计大量被取代；有限元、优化设计等现代方法使机械设计效率与精度跃升。

航天领域：苏联发射人类首颗人造卫星，加加林首次进入太空；美国完成载人登月，并发展可重复使用航天飞机等路径；**1970** 年中国成功发射第一颗人造地球卫星「东方红一号」，跻身航天国家行列。原子能从武器应用走向和平发电：苏联奥布宁斯克等电站常被记为早期并网核电里程碑。计算机与伺服控制结合，工业机器人进入焊接、装配、搬运；特种机器人延伸至深海、医疗与极端环境作业。

全球经济格局走向多元：美国作为科技与金融中心，冷战后一度成为唯一超级大国；日本凭借加工贸易、技术引进与精益管理，约 **1968** 年成为资本主义世界第二大经济体；西欧依靠区域合作完成战后复兴；苏联依托计划经济快速推进工业化，也因体制僵化等因素埋下后期危机。第三次工业革命的「信息层」，最终强化的是**美国晚期霸权的网络与标准优势**——与第 7.2 节「科技与高等教育」直接咬合。协议与入口如何收束流量，见 [14](./14-internet-history-chronicle.md)；计算如何变成资源池，见 [10](./10-computing-cloud-chronicle.md)。

### 8.5 工业 4.0：数字化、智能化与过渡期

**时间：** 约二十一世纪初至今；政策语言上仍处演进，许多组织认为正处于**第三次数字化向第四次融合过渡或叠加**的阶段。[^schwab]

核心技术簇通常包括人工智能、大数据、物联网、云计算、增材制造（3D 打印）等，目标是打通物理世界、数字世界与生物世界的边界；智能工厂、人机协同、机器自组织成为发展方向。主要大国纷纷布局顶层战略：美国推动**工业互联网**与信息技术赋能制造业；德国提出 **Industrie 4.0**；日本规划 **Society 5.0**，强调以人为本的超智能社会。[^industry40-paths]

在这一轮浪潮中，中国实现快速工业化与数字化叠加：建成门类齐全的工业体系，高铁、5G、新能源汽车等赛道进入世界前列；数字经济规模居全球前列，并长期保持世界第二大经济体、货物贸易大国地位——走出**中国式现代化**语境下的工业化路径。须同时记住第 9 节的边界：工业与贸易崛起是产能与增加值故事，**不等于**已完成全球公共品意义上的霸权交棒；算力、芯片、标准与关键矿产上的竞争，才是 4IR 改写霸权形态的前线（见第 9.5 节）。产业如何被智能穿透、护城河迁到数据与流程，见 [50](../50-strategy/50-ai-industry-disruption-strategy.md)——那是企业战略，不是谁接过最后贷款人。

### 8.6 回望：多元工业化道路

四次工业革命不只改写「有什么机器」，也沉淀出若干可对照的国家道路——它们解释为何同一技术浪潮下，权力果实落点不同：

| 道路（简化标签） | 典型经验 | 与本文霸权叙事的接口 |
| ---------------- | -------- | -------------------- |
| **英国：原生型 / 先发工业化** | 借第一次工业革命登顶（五台引擎凑齐，见第 8.2.3 节）；先发不等于十八世纪前已全面领先（见第 8.2.1 节）；后期受旧产业与帝国成本束缚 | 第 5 节 Pax Britannica；金融化与工业被追赶 |
| **美国：市场主导 + 规模纵深** | 持续把握第二、三次（及部分第四次）科技与组织红利；大陆市场与移民国家放大流水线与创新生态 | 第 7 节生产—美元—同盟；[55](../50-strategy/55-global-manufacturing-migration-chronicle.md) 世界工厂西移 |
| **德国：莱茵模式** | 国家引导、双元教育与硬核制造业深度结合；Industry 4.0 话语的重要源头 | 第二次工业革命赶超；当代标准与装备出口 |
| **日本：政府引导的追赶** | 贸易立国、技术立国与精益管理；战后高速增长至第二大经济体 | 第三次工业革命中的追赶典范；泡沫后调整 |
| **苏联 / 中国：规划型工业化** | 以国家规划推动重工业与完整产业体系；中国在改革开放后叠加市场与全球化 | 冷战两极与当代产能中心；中国路径见第 8.5 节、第 9 节 |

工业的演进从未止步。从简单杠杆到人工智能，技术迭代不断打破旧的生产力边界，也持续改写国家力量对比与生活方式。

**趋势含义（收束，与开篇总表呼应）：**

1. 前两次工业革命仍强烈绑定「工厂 + 领土 + 海权」。  
2. 第三、四次越来越绑定「数据、标准、平台、算力与人才网络」。  
3. 霸权竞争从「谁的烟囱更多」扩展到「谁的协议、芯片、模型、能源与关键矿产更多」。  
4. 2020 年代的政策语言已明确把 AI / 半导体供应链写成**经济安全与同盟政治**（见第 9.4–9.5 节），而不仅是产业政策。  
5. **道路多元：** 先发、追赶、规划与莱茵模式可以并存；技术浪潮是共有的，制度与公共品供给能力决定谁把浪潮写成秩序。

与本库技术编年的接口：[10](./10-computing-cloud-chronicle.md) 云计算与资源池、[11](./11-information-theory-chronicle.md) 信息度量、[12](./12-artificial-intelligence-chronicle.md) AI 机制与阶段、[14](./14-internet-history-chronicle.md) 协议与入口——分别是第三、四次工业革命的底层故事；产业穿透见 [50](../50-strategy/50-ai-industry-disruption-strategy.md)，产能地理见 [55](../50-strategy/55-global-manufacturing-migration-chronicle.md)。本文把它们放回权力秩序里读。

## 9. 当代：未完成的交棒、多极辩论与地缘技术

### 9.1 什么已经变了

- **权力分布：** 中国在制造业增加值、贸易量与部分基础设施输出上显著上升；欧盟、印度、中等强国与地区组织的权重上升；美国仍在军事投送、深层金融市场、高等教育与诸多前沿科技上领先。  
- **秩序形态：** 多边机构承压；区域贸易与「友岸 / 近岸」并行；安全与经济政策更紧耦合（地缘经济）。  
- **技术：** 第四次工业革命议题（AI、半导体、生物、绿色能源）成为国家竞争的核心赛道。  
- **美国国内：** 对「继续支付全球公共品成本」的共识弱化；产业政策回流与联盟政策并行，而非简单孤立。

### 9.2 什么还没有发生（必须写清）

- **没有**出现像 1945 那样清晰的「制度性交棒仪式」。  
- **没有**单一继承者同时具备：全球安全同盟网络 + 顶级储备货币深度 + 全面科技前沿 + 愿意并能够开放市场吸收世界过剩产能。  
- 因此，更贴近证据的表述仍是：**单极时刻意义上的「无人匹敌」已经结束；美国体系性领导权大幅仍在，但意愿与合法性波动；中国是最重要的挑战者与相互依存伙伴，而非已完成的霸权继承者。**

### 9.3 专业文献中的分歧（2025–2026）

当代判断不宜只听一种口号。至少三组论点并存：

| 论点 | 大意 | 代表取向 |
| ---- | ---- | -------- |
| **A. 多极已成 / 后美国世界** | 旧秩序已弃；世界将经历无单一秩序的碎片化、传染与扼制；不是短暂间歇后的「中国治世」 | 如 *Foreign Affairs*「被遗弃的秩序」一类论述[^abandoned-order] |
| **B. 多极是幻觉，单极变形** | 军事与经济体量上仍难出现可信挑战者联盟；变化的是美国更少自我约束、更强势投射 | 如 *Foreign Affairs*「多极幻觉」一类论述[^multipolar-delusion] |
| **C. 霸权因自我选择而削弱** | 相对衰落不只来自外部崛起，也来自美国主动收缩公共品与同盟信誉；恢复可能，但形态不同 | 如 PIIE「美国霸权是否终结」讨论[^piie-hegemony] |

读者应同时看见：**「多极」既是描述，也是政治修辞**；描述是否成立，要拆开军事、货币、科技、意愿四维分别度量。

### 9.4 反向金德尔伯格陷阱与金融间歇期

1930 年代公式是：**英国不能，美国不愿。**

2020 年代部分研究提出镜像风险：**美国作为守成国仍具备深度网络与货币中心地位，但供给自由秩序与金融稳定的意愿受国内政治与政策冲击而动摇；中国等崛起方寻求自主与影响力，却尚未能（或不愿全面）承担替代性全球霸权责任。** 美元的网络效应使「去美元」缓慢，替代货币亦未成型——结果更像**金融间歇期（financial interregnum）**：碎片化、集团化支付与地缘化资本流动增加，而非干净利落的货币交棒。[^dollar-interregnum]

这与第 6 节的历史顾虑直接对话：空窗可以来自「不能」，也可以来自「不愿」；今日两者可能同时以不同比例存在。

### 9.5 第四次工业革命的地缘技术化

霸权竞赛日益表现为对**算力—芯片—能源—关键矿产—标准**整条生态的组织能力：

- 政策语言上，AI 不再只是应用创新，而被表述为工业体系的操作系统与「国际战略竞争主战场」（中美双方高层论述均有此取向）。[^geo-tech]  
- 供应链上，出口管制、友岸联盟与矿产安全把第四次工业革命嵌进同盟政治；美国推动的 AI / 半导体 / 关键矿产合作框架（如 2025 年末起报道的 **Pax Silica** 等倡议）试图把创新优势组织成可扩展的伙伴生态，而非仅靠单点技术领先。[^pax-silica]  
- 与 [55](../50-strategy/55-global-manufacturing-migration-chronicle.md) 合读：组装外移、近岸与增加值仍留中国中间品，说明**产能旗号与权力网络并不一一对应**——正如双边贸易脱钩快于增加值脱钩。产业穿透（数据、流程、护城河）见第 8.5 节所引 [50](../50-strategy/50-ai-industry-disruption-strategy.md)，接不上最后贷款人与同盟网络。

### 9.7 与「修昔底德陷阱」叙事的距离

权力转移理论与通俗「修昔底德陷阱」提醒崛起—守成结构下的战争风险；但严肃研究也指出：案例多取自欧洲史，且战争并非唯一出路；经济相互依存、核威慑、国内政治与制度绑定都会改变概率。[^power-transition] **历史顾虑应当是「管理过渡」，而不是「宣布战争命运」。** 同样，把「多极」或「单极变形」说成已闭合事实，也会妨碍对公共品真空的警惕。

### 9.8 全球不平等与五条出路（波德）

全人类都会碰到全球化的某一面：消费、信息、商业、资源与环境。波德指出，图景背后多数人仍可能处在边缘——真正推动全球化的，是三种力量：**以美国为首的资本主义大国、超大跨国公司、资金雄厚的金融投资家。** 新技术往往先在主导国家内部发生，复杂后果却由更多国家分担。美元流动性外溢，也会拉大国家之间、阶层之间的金融不平等。[^beaud]

面对这种不平等，他列出五条常被讨论的出路，都不是已经走通的政策：

1. **压人口**——历史上有人提过，伦理与政治上都站不住。  
2. **绿色资本主义主导**——设法约束能源、食品、气候、生物与人类活动的任意扩张。  
3. **放任发展，分区隔离**——把奢华享乐区与穷人区分开。这是描述一种可能滑向的秩序，不是推荐。  
4. **经济路径：鼓励绿色生产模式。**  
5. **社会路径：尽量满足穷人的生活必需，减少不平等，加强人类团结。**

波德自己的收束很冷：资本主义与经济全球化极复杂，结构性变化极艰巨，任何出路都要在更高层面达成共识。巴黎协定尚且波折不断，涉及更多层面的调整只会更难。这与第 9.4 节公共品意愿、第 10 节「产能故事 ≠ 秩序故事」同读：不平等是体系产物，不是再加一轮增长自动消失的余数。

## 10. 历史顾虑与可带走的判断

1. **空窗期比「谁当霸主」更危险。** 1929–1939 表明：英国不能、美国不愿，足以让体系失控。当代若出现「美国收缩公共品 / 中国尚未能提供同类全球公共品」的组合，风险在失序，不在称号——这正是反向金德尔伯格讨论的现实指向。  
2. **金融化是成熟信号，也是危机伏笔。** 荷兰资本流入英国、英国金融城繁荣而工业被追赶、美国金融膨胀与产业外移——节奏不同，结构相似。  
3. **工业革命改写武器，不自动改写合法性。** 第一次工业革命首先改写的是生产函数与能源基础，而不是证明「欧洲从来更厉害」；技术领先还要转化为财政、同盟与规则能力，才成霸权。4IR 下还要转化为供应链与标准生态的组织能力。多元工业化道路（英先发、美规模、德莱茵、日追赶、规划型）说明：同一技术浪潮下，制度与公共品供给决定果实落点。  
4. **小国网络型霸权难持久；大陆—财政国家更耐久——但帝国过度扩张与自我放弃同样致命。** 荷兰与英国给出两端教训；PIIE 等当代讨论则提醒「自我选择的收缩」。  
5. **趋势是尺度更大、议题更技术化、权力叙事更嘈杂。** 完全单极更难维持「自愿追随」；完全无锚的碎片化也可能更动荡。多极是修辞还是结构，需分维验证。  
6. **对中国与世界的取势：** 制造业四次大迁移（[55](../50-strategy/55-global-manufacturing-migration-chronicle.md)）是产能故事；霸权转移是秩序与公共品故事。二者耦合：没有工业与科技底座，难谈领导权；没有可被他者接受的公共品供给，工业崛起也不自动等于霸权。

## 11. 本章要点

1. **三次主导现代霸权：** 荷兰（十七世纪商业—金融）→ 英国（十九世纪工业—海权—自由贸易）→ 美国（二十世纪中叶以降生产—美元—同盟）。  
2. **理论透镜：** 体系积累周期、霸权稳定论、权力转移——用来提问，不用来算命。波德通史是旁证：金银不等于资本主义；英国三波红利；1873 长期萧条是 1929 的前史；美国靠管理—金融—科技三因重塑；全球化三种力量与五条出路见第 9.8 节。  
3. **最惨痛过渡课：** 1873–1896 先磨掉英国的相对工业优势；1914–1945 尤其「英国不能、美国不愿」。  
4. **四次工业革命：** 前史机械积淀 → 蒸汽机械化（英：飞梭—纺纱瓶颈—蒸汽不停转；五台引擎凑齐，而非人种；「大分流」奇点，而非文艺复兴以来一路领先）→ 电力与流水线（美德赶超）→ 电子信息与自动化（美晚期优势 + 日欧苏多元）→ 物理—数字—生物融合（当代开放竞赛）；道路含英先发、美规模、德莱茵、日追赶、苏 / 中规划型。聪明往哪流，社会就长成什么样。  
5. **当代：** 过渡与竞争；多极辩论存在尖锐分歧；反向金德尔伯格与金融间歇是新增顾虑；地缘技术（芯片—AI—矿产）成为霸权新战场。  
6. **两种错误：** 失序麻木（忽视公共品真空）与宿命论（宣称战争或交棒已注定）。
